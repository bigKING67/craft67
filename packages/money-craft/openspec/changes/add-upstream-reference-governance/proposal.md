# Change: Add upstream reference governance

## Why

Money Craft currently checks only AI Berkshire. The user approved an owned research
core shared by a Skill and a future application, with selective references from
multiple projects and the 155-page MyInvestPilot public documentation catalog.
References need durable coverage, immutable baselines and honest update states.

## What Changes

- Add an upstream strategy and original, page-level MyInvestPilot review.
- Extend the source lock additively with versioned reference tracking metadata.
- Preserve the legacy AI Berkshire CLI; add multi-source checks and document capture import.
- Separate cached, current, pending-review, stale and unavailable observations.
- Add offline behavior tests and preserve runtime packaging boundaries.

## Impact

Affected capability: upstream-reference-governance. Repository maintenance only;
no investment runtime dependencies, account operations, application framework,
installation, commit, push or release. Existing provenance and research behavior remain.

## Authorization

The user approved the staged plan, confirmed Skill/shared core before application,
and explicitly requested “Implement the plan.” This record captures that accepted
scope; it does not introduce a new approval gate or authorize later capability batches.
