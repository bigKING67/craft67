## 重放

在仓库外准备上述原始 PDF，文件名分别为 `600519-2023-annual-report.pdf` 和 `600519-2024-annual-report.pdf`。完整 PDF 不随仓库或运行包分发。

```bash
python3 scripts/check_earnings_case.py \
  --evidence-dir <存有两份原始PDF的目录> \
  --output-dir <尚不存在的新输出目录>
```

命令重算文件哈希、调用 earnings 核心、使用已人工确认的当前样例生成 tracking 工作区，并执行封存和离线验证。已有输出目录会被拒绝，历史案例不会被覆盖。`earnings-update.json`、`acceptance-receipt.json` 和 `tracking/revisions/t0001/` 保存在输出目录；软件仍不自动核实 PDF 的语义。

也可将 `600519-2023-2024.json` 放到 PDF 同目录，单独运行 `money_craft.py earnings review --input <JSON> --previous-thesis acceptance/earnings/600519-previous-thesis.md --json`。input source 路径按 JSON 所在目录解析。
