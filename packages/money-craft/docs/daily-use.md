## 从研究问题进入

| 用户问题示例 | 执行与交付 | 何时停止确定性结论 |
|---|---|---|
| “这家公司值不值得继续研究？” | 解析证券、币种与日期，先排雷；给事实、反方、资料缺口和下一步 | 身份歧义、关键事实无法核实、重大矛盾未解决 |
| “这份新财报改变了什么？” | 对齐财政窗口，核利润与现金，比较旧假设，明确下一观察期 | 缺累计窗口、不可比重述、非GAAP口径不清时停止对应计算 |
| “按这个盈利和倍数估值合理吗？” | 检查当前/正常化基线和假设依据，再给敏感性或有依据情景 | 倍数无依据时只作演示；现金归属与限制不清时不加回 |
| “原来的投资判断还成立吗？” | 读取旧论文与证据，逐项更新假设/红线，保留历史，说明变更原因 | 无合格旧论文时先形成观察记录，不伪装成正式track revision |
| “这组基金/持仓怎么配置？” | 先确认证券身份、资金用途、期限、基础币种和可承受损失 | 基金原始资料到组合核心及安装宿主已作有界验收；完整持仓、跨来源身份或价格序列缺失时保留未知，不冒充优化器 |

用户可同时给报告、旧论文或持仓；缺少会影响范围的信息才澄清。没有指定日期时先核当前日期并明确数据截止。历史回放保留原as_of及本次取得时间。观察任务必须写明具体财政期及同比/累计窗口，未获取后续资料不等于尚未披露。

完成一次研究时，读者应能看到：结论与置信边界、关键证据定位、计算、最强反方如何影响判断、尚缺什么、下一次检查哪个期间。引用数、机器PASS与收益保证是不同概念。正式档案和发布仍遵循已有授权与运行账本规则。
