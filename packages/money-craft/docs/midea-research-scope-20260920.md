# 美的研究的已知事实与未决依赖

2026-09-20。用户追问公开上市公司为何仍不能完成分析后，复核原P01及研究完成合同。此前把“本次未完全核实”表述得接近“无法解决”，并把多个主张放在同一个UNVERIFIED项内，混淆了研究范围。原始验收文件不回写。

| 主张 | 当前支持程度 | 对研究的影响 |
|---|---|---|
| 经常/非经常分类对扣非的影响 | 公司正式解释可定位，S11页7及S19问答 | 可解释指标为何不能直接代表主业变化，不证明主业增长幅度 |
| A/H披露汇兑总额与拆分 | 两期明确披露对齐，S11页173、S24印刷页136 | 可陈述列报拆分，同一发行人不冒充独立双源 |
| 衍生品表内/文字与OCI关系 | 精确算术及原页支持，解释仍INFERRED，S11页55—56、170 | 可提供有条件的口径解释，不能重复计入重分类收益 |
| 集团净利润到经营现金流 | 附注及逐项计算闭合，S11页177 | 可分析集团现金质量，不等于逐笔结算或股东可分配现金 |
| 套保与所有敞口逐项对应 | 尚未完整核实 | 阻断宣称完全抵销和该口径的确定性正常化 |
| 正常化税后归母及可持续主业盈利 | 仍缺完整范围、税项/归属和可持续性论证 | 阻断依赖它的确定性估值；不否定已有事实分析 |

当前P01将会计分类、谨慎经营解释、未核实现金桥放在一个对象内；核心又对该对象UNVERIFIED直接阻断finalize。其他状态已经区分complete、claim_support及evidence_coverage。因此需要先重建细粒度的主张及依赖，才能判断是输入粗糙还是完成合同需要调整。不能为获得PASS直接把P01改成OBSERVED，也不能因正常化未知就断言公司出了财务问题。

公开报表提供大量财务和风险信息，但特定研究者定义的“正常化主业利润”还包含范围选择与持续性假设。公开可获得性、摘录核对、同口径调节和未来判断是不同层次。本案例已有事实足以推进有边界研究；余项应列出需要的正式明细、解释或情景假设，而非无限寻找一个不存在于报表的现成答案。

本轮未修改财务核心门禁或原研究结论。后续研究新版应分别标注OBSERVED/INFERRED/UNVERIFIED，并保留未决事项对结论与估值的限制。完整合同调整需带正反样本验证，不能借工程完成宣称投资决策就绪。
