# 研究语义验收

用于完整公司研究、估值与论文交付前，以及已封存材料的语义复核。机器 report/financial/reconciliation audit 验证结构、计算与绑定；此处由实际阅读来源的研究者判断论点，不能把人工结果写成机器 `assessment.claim_support` 或 `source_freshness` 已自动认证。复核历史材料时保留其 as_of，不自动刷新成当前结论。

## 关键主张与依赖

围绕会改变结论的主张逐项记录，不为凑数量拆分事实：

| 项目 | 必须回答 |
|---|---|
| 主张与状态 | 报告具体说了什么？属于 OBSERVED、INFERRED、HYPOTHESIZED 还是 UNVERIFIED？ |
| 证据定位 | 来源 ID、文件 SHA-256、页码/表格/段落是什么？是否同证券、期间、币种及合并范围？ |
| 支持边界 | 原文支持哪个范围？发行人解释、研究者推断与独立核实是否分开？ |
| 来源血缘 | 两个入口是否转述同一份披露？Provider 字段映射一致只证明转录对照；未确认独立性时记录缺口，不能声称独立双源验证。 |
| 反方与影响 | 最强反方是什么？接受它后，哪条假设、哪个估值输入或最终判断需要改变？ |
| 未决事项 | 缺失哪个可观察事实、由何种来源补足、复查哪一期？不能仅在末尾写泛泛免责声明。 |

逐项结论用 `SUPPORTED_WITHIN_SCOPE`、`UNVERIFIED` 或 `CONTRADICTED`，附理由和对下游判断的实际影响。来源缺失不等于主张为假；假设未获支持不等于已被证伪。

## 估值与反方验收

- 客户导入及商业化主张按 [financial-data-and-evidence.md](financial-data-and-evidence.md) 的“业务进展到财务结果”边界复核：框架、定点、订单、交付、收入和回款各自支持什么；是否重复计数、跨期间或从订单直接跳到归母利润。条件订单仍有信息价值，不因结果不确定就抹去真实进展。

- 数值、公式正确但基线/倍数无依据时，仅作为敏感性演示；不得据此给合理价值区间、目标价或安全边际。该限制须出现在估值表说明和最终结论中。当前/正常化基线按 [valuation-and-thesis.md](valuation-and-thesis.md) 判断，不用机械加减固定百分比代替经营论证。
- 先识别反方证据会改变的驱动项，再决定是否量化。无法可靠量化时停止依赖它的确定性估值，不强行给虚构悲观数值。
- 分项复算与披露合计不同，即使低于跨来源差异阈值，也不能直接解释为舍入或静默选值。按 [financial-data-and-evidence.md](financial-data-and-evidence.md) 核对口径与舍入依据；未决差异须在采用该输入的情景和结论旁出现。真实残差的计算回执通过，不等于披露已核对一致；核查报告是否保留了这一区别。
- 期后价格变化不解释之前期间的已实现业绩；公布提价不等于销量、渠道承接或利润增量已验证。集团OCF增长与集团可用现金不自动等于主业现金转换或母公司可分配现金。
- `OCF − 购建长期资产现金支出`只能按其明确范围称简化FCF/proxy。未完成债务偿付、租赁、少数股东、受限及经营必要资金等桥接时，不将该proxy称股东可得或可自由分配现金，也不以“可用现金”含糊替代。
- 票据贴现带来的经营现金改善不自动证明客户回款能力增强，也不自动否定现金流真实性。调整前须区分期间贴现收款与期末未到期余额、背书与贴现、终止确认与未终止确认及现金流分类；未完成桥接时，不用期末“已背书或贴现”余额直接扣期间OCF，保留已披露OCF及其解释限制。
- 扩产分析分别记录项目预算、累计会计投入、在建工程余额与实际现金付款；转固不等于付款，预算减账面余额不等于剩余现金需求。设备、研发、营运资金、应付款及预算修订范围未齐时，只交付已支持的项目预算和支出事实，不将局部缺口扩写为“所有预算均未披露”，也不自动把增长支出加回现金流。
- 判断经营现金能否覆盖扩产时，主动核对资产负债变动说明及购置款附注中的付款方式。若设备或厂房以承兑汇票、赊购或其他非现金方式结算，在结论中说明现金购建支出未覆盖的义务；期末票据/应付款存量不直接当本期新增资本开支。比较程度先按同口径数据计算，再使用“接近”“明显不足”等表述；若过程消息已有相反或夸大的判断，最终明确纠正。
- 证伪条件要写明可观察指标、比较口径、报告窗口、触发后的状态变化。累计、单季与TTM分开；衍生单季需要两个累计期间及可比基数。缺少其中一个窗口则保持 UNVERIFIED，不能把推算值称为独立披露值。
- 完整论文的盈利、经营质量、估值等关键依赖未覆盖时，按已有论文合同补齐；若证据不足，交付“研究观察/敏感性演示”，并明示尚不能完成的投资判断，不用章节齐全或 completion receipt 声称完整投资研究已完成。
- 收口分别说明流程完成状态、已支持结论及其范围、未决投资假设。缺口只阻断依赖它的判断，不把局部UNVERIFIED扩散为所有事实不可用；若已有有界检索不足以取得尚未披露的数据，给出可观察触发条件和复查窗口后停止重复检索。用户继续时，推进仍可解决的问题；不存在有效补证路径时直说，不以重复报告或新增文档冒充进展。新披露、价格或范围发生实质变化时再重启相关核查。

## 结果与错误变体验收

### 现金、债务与法人边界

研究涉及现金可用性或净债务时，逐项复核以下容易在算术正确时仍出错的解释；不要求无相关业务的公司机械增加科目。

- **法人范围**：先辨认合并/母公司列。集团现金、母公司现金与内部往来不能相加；母公司“现金减选定借款”的余额不自动是分红空间。其他应付款缺对手方及偿付安排时，不假定全是内部资金池或永久可占用资金。投资收益汇回无重大限制不等于本金及全部子公司现金可自由调度。
- **债务重分类**：沿附注追踪流动与非流动部分，留意其他流动负债内的融资工具；零票息可转债不等于没有偿还义务。同一债券或租赁在附注和报表出现多次只计一次；账面金额、合同本金和含息到期现金流分别列示。母公司债券余额为零不排除担保，集团已入账债务不再因担保重复计入。
- **扩产偿付覆盖**：用户询问融资后资金是否充足时，偿付核查覆盖短期借款、一年内到期部分、非流动借款及租赁等已披露义务；短期小计明确其范围，不能代替全部债务。将其与付款时间、用途及法人限制衔接，不能仅凭现金减借款的静态差额判定危机或长期充足。跨文件归还状态有矛盾时，同时核对主报告的相关说明；“尚未到期”不能替代“已归还”的证据。
- **现金扣减**：先重建货币资金到现金等价物的桥，已排除的受限项不得从现金等价物再次扣除。差额没有逐项解释时，不全称受限现金；境外、金融业务和质押等分类可能重叠，不能逐项全扣后称保守可用余额。
- **期限与解押**：区分取得时期限、剩余期限和报表重分类；一年内到期不等于即刻或指定月份到账。核对质押所在桶、解除条件、续存及退出条件；仅有汇总余额时，分桶敏感性不能命名为可用资金上下限，也不能把未知资金设为零并声称已验证的保守估值。

维护用的四组正反例见仓库 `acceptance/liquidity-semantics/cases.json`，通过 `python scripts/check_liquidity_semantics.py --output <receipt.json>` 重放。该命令只记录结构/计算审计和预设人工标签，**不执行独立语义评审，不是宿主 Skill 自然语言验收**；真实宿主验收须隔离答案，给出事实与任务后，再由实际评审者对照标准判断。

期间、票据、扩产预算、产品归属、敏感性估值与研究收口的六组补充样本位于 `acceptance/liquidity-semantics/research-boundaries.json`，用同一命令加 `--cases acceptance/liquidity-semantics/research-boundaries.json` 重放。样本为合成事实，沿用上述证据边界；错误解释通过结构与算术检查不表示语义正确。

记录输入哈希、实际复核者（含是否自审）、已检查主张、未决事项及交付范围。已封存材料产生新补充记录或按跟踪合同产生新版，不能原地改写原报告及旧验收结果。独立复核只有实际完成才可宣称；本流程不隐含多代理授权。

维护或验收本 Skill 时，可制作少量只改变解释、不改变计算的错误变体，例如“提价已兑现利润”“合并现金全可分配”“敏感性中性值就是目标价”。每例保留错误主张、反证定位、人工判断及机器实际结果。机器仍通过计算正是其边界，不能把人工识别写成程序自动拦截，也不能把自设样本全部识别当作留出或泛化成绩。复核样本通过只证明该样本和声明标准，不能抹去真实研究中的未决依赖。
