# Product context: Reviewlane

## Register

- Platform: web
- Surface mode: `Persuade`
- Surface: project-neutral product landing page
- Evidence status: repository-local controlled fixture, not production evidence

## User

Frontend leads and design engineers evaluating whether a visual-review tool can
turn scattered screenshots and checks into a release decision.

## Primary job

Understand the offer, see one concrete example of the resulting review bundle,
and decide whether to start a review or inspect a sample report.

## Product promise

Reviewlane turns visual review into a release decision by connecting route,
state, viewport, and evidence coverage in one bounded review bundle.

## Content inventory

- Product name: Reviewlane
- Primary headline: Turn visual review into a release decision.
- Supporting sentence: See every route, state, and viewport that still needs a
  decision before release.
- Primary action: Start a review
- Secondary action: See sample report
- Proof labels: 12 routes reviewed, 3 unresolved states, 2 viewports verified
- Workflow: Capture, compare, decide
- Final action: Start with one release candidate

Both experiment variants must use this exact inventory. A variant may change
composition and responsive order, but not claims, information volume, product
scope, or available actions.

## Accessibility and trust

- Use semantic landmarks and one visible `h1`.
- All controls must be keyboard reachable with visible focus.
- The sample report must use a native dialog with an explicit close control.
- Reduced-motion users receive no entrance or scroll motion.
- Sample metrics are visibly identified as demonstration data.
- Do not imply production integrations, customers, compliance, or measured
  performance that the fixture does not prove.

## Out of scope

- Authentication, billing, persistence, network calls, analytics, or backend.
- Production conversion, retention, or performance claims.
- Reuse of third-party copy, brand assets, screenshots, or distinctive layout.
