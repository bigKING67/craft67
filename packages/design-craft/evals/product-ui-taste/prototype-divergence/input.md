# Prototype divergence golden input

This is a project-neutral textual fixture. It does not request real code,
browser execution, or production changes.

## Task

Prototype three genuinely different result-summary panels for a desktop command
palette. The panel appears after a long-running workspace search and must help a
developer understand what changed, inspect warnings, and choose the next action.

## Authority and constraints

- The product is a dense daily-use developer tool.
- Existing compact controls, typography, spacing, and focus tokens remain
  authoritative.
- The prototype may use an isolated preview surface only. Production command
  palette files and shared primitives are excluded until selection.
- All directions use the same realistic fixture: 38 files scanned, 6 changes,
  2 warnings, one skipped generated file, and actions to inspect, apply, or
  dismiss.
- Keyboard navigation, visible focus, Light/Dark parity, long paths, and Reduced
  Motion are required.
- Color-only, copy-only, and decoration-only variations do not count as distinct
  directions.

Produce the exploration plan and stop before implementation or promotion.
