# Team Workflow Craft

- 本包是成员本地的跨宿主协作 Skill；唯一安装运行时是 `skills/team-workflow-craft/`，运行时不能导入包外代码。Python 3.11+、Git，标准库优先。
- v0.1 边界：CNB/Gitea 只读、任务快照、Git 检查/显式 worktree 创建、批准命令的验证证据、交接草稿、固定产物安装。禁止隐式发布、提交、推送、合并、部署、模型调用、Agent 启动或常驻服务。
- L0 不创建任务或文档；复杂度和风险独立。已有 Trellis 托管流程只接工具，不接管生命周期。快照可重建，不是第二个任务数据库。
- Git 检查覆盖整个实际 Git 根，包括其他包 WIP。不得 stash、reset、clean、覆盖现有工作区。工作树不是服务/数据库沙箱。
- 未运行、依赖缺失、超时、取消、代码/策略漂移都不算通过。证据绑定 base/head、dirty 内容、命令、策略和退出码；本地哈希不构成可信执行证明或合并授权。
- 凭据仅从显式配置的环境变量读取，不放 URL/配置/日志；禁打印响应体与原始 HTTP 错误。HTTP 重定向不得携带凭据跨域。验证子进程会执行项目代码，必须明确批准，不称只读。
- 外层 scripts 只负责开发、打包、安装。安装仅写显式目标，拒绝覆盖未知/漂移副本，不改全局宿主配置或账号。
- 门禁：`python3 scripts/check.py`。测试用临时 Git 仓库和本地模拟 HTTP，不接真实公司平台，不调用付费模型。源码、离线合同、安装一致性、宿主加载、live 和远端发布分别报告。
