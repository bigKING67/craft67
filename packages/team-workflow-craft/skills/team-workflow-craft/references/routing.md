# 流程与风险

只在协作需要时使用 TWC。修改按钮文案、修复局部错误等 L0 按原项目工作流完成，不为了启用本 Skill 而 init/建任务/写模板。一次跨人接手属于 L1；多人改变同一接口、数据库迁移或共同发布属于 L2。

`normal` 采用相关项目检查；`elevated` 增加受影响调用方、失败路径和回归；`critical` 如鉴权/权限/高风险数据变更，需要明确信任边界、回滚限制与可信独立审查。这里的风险不授予写入、发布或代理权限，也不代替项目现有门禁。

示例：单人修复鉴权是 L1 + critical；三人实现普通后台是 L2 + normal。高风险校验不能因任务文件少而省略，多人任务也不因此启动完整安全审计。

只读诊断不修改代码。实现请求完成范围内改动及验证；没有实际需求不增加后端、通用协议、另一套任务数据库或模型路由器。
