# 中文创意判断力评测材料

这是六个原创虚构任务与人工盲选说明。材料本身不构成运行证据或质量提升结论；
实际执行情况以绑定题目、Skill 快照和原始输出的独立运行记录为准。
它不接入现有 `evaluate_agent_quality.py`，不改变其九个质量案例、四个路由案例、
默认调用上限或评分合同。不要把这里的 JSON 直接传给现有 CLI；它是待评测材料，
不是新的公开工件 Schema。后续自动接入或付费运行需按实际授权范围安排。

## 题目使用与保留题

- `development.json`：四个诊断任务，覆盖不完整 brief、产品差异化概念、
  中文短标题与正文、感官文案。
- `holdout.json`：两个保留任务，覆盖静态视觉方向和短视频创意。
- 每个任务的 `prompt` 是生成端唯一接收的题目内容。`id`、`title`、`expected_mode`
  和 `split` 用于材料管理，不附带标准答案或创意机制提示。
- 首轮 Skill 内容冻结后才使用保留题评估。不要根据其输出修改规则后，继续将同一批
  题目称为未见验证；一旦用于调优就转为诊断材料，并另建保留题。
- 文件分开只是流程边界，不是保密或技术隔离。这些题目在仓库中可见；评测记录需
  说明是否暴露给生成端或被用于调优，不声称严格的统计独立性。

六个任务都是文字交付。视觉、视频题仅评价方向或脚本，不能证明图像质量、产品
保真、动作物理或真实成片节奏。

## 后续比较条件

比较三种条件：不加载 Skill、改前 dirty candidate、改后 candidate。改前 Skill
以本次实施前保存的内容快照为准；HEAD 不包含当时全部 WIP，不能替代改前基线。
每个条件绑定具体文件摘要，并固定题目、模型、reasoning、上下文及授权范围。
生成端不得看到本说明、其他条件的回答、评价结果或教学案例之外的评测材料。

先验证来源隔离：无 Skill 条件没有读取 Creative Craft；其余条件只读取各自
绑定的 Skill 副本。出现跨条件读取则标记 `INVALID SAMPLE`，不能继续用该组
分数证明质量增益。保留原始回答与失败样本，不挑选最好的一次替换原始记录。

只有后续明确授权执行后才生成回答。若使用每题三条件各一次生成、一次模型盲评，
六题共 24 次文本模型调用；这个计算不是调用授权，也不包含重试或重复取样。
首轮实施只做离线材料检查，不创建虚假的回答、盲选或运行回执。

## 人工盲选

后续模型盲评可使用 [judge-prompt.md](judge-prompt.md)。它明确区分相对偏好、
采用意愿和重写负担；尚未验证其判断效果，不改变下方人工评价方法或默认 CLI。

将同题三份原始回答随机标为 A/B/C，隐藏来源、文件名和其他条件信息，映射另存。
评价人先看用户原题与作品，再写意见，最后解盲。不得为匿名而改写作品或删除其
不利内容；回答自述 Skill 身份时记录盲法可能失效，不能假装完全盲评。

每题独立填写以下项目，允许平局和全部不选，不强制产生赢家：

| 项目 | 记录方式 |
| --- | --- |
| 采用意愿 | A / B / C / 平局（列出标签）/ 全部不选，并说明用途 |
| 产品关联 | 指出哪句、哪个画面或动作承载了产品事实；是否换个产品仍完全成立 |
| 记忆点 | 具体指出记住什么、为何与任务相关；不把猎奇自动当优势 |
| 表达质量 | 中文自然程度、节奏、信息取舍、图文或时序关系；引用作品片段 |
| 事实与格式约束 | 列出满足、违反或无法确认的项目，不用好文笔抵消虚构事实 |
| 重写负担 | 可直接用 / 局部修改 / 方向重做，并指出需要修改的部分 |
| 判断局限 | 缺少品牌背景、仅见文字方案、个人偏好或其他不确定性 |

先判断作品能否成立，再阅读其说明是否有助于执行。解释完整、篇幅长、术语多均不
是独立优势。没有唯一风格偏好：幽默、克制、直白演示、情绪表达都可能适合任务。
对即时消费场景，还要判断文案是否说到具体需求或处境；感官画面、品牌名联想和
情绪词不能自动算作有效表达。按原题的产品、受众和版位判断，不把直白或文艺本身
当作普遍加分项。不得为迎合参考广告而擅自更换原题的传播场景。
引用到的用户字数约束应按题目口径实际检查；视频时长只凭脚本不能认定实测通过。

## 如何解释结果

按题目呈现选择、理由、约束问题和重写负担；分开汇报诊断题与保留题，不制造一个
“创意能力总分”。候选出现重要事实错误时明确列出，即使它在记忆点上被选中。
人工意见代表该评价人和这些任务，模型评价也仅是比较证据，均不是市场效果证明。
“非要选某个，但都不喜欢”应记录为全部不采纳，将被迫排序单独保留；不能折算为
该版本通过或胜出。人类判断与模型选择不一致时保留两者及人类理由，不改写旧结果。

单次样本不支持稳定提升。后续若要声称稳定增益，需要另行设计重复取样与未参与
调优的题目；保留所有运行，记录来源、评测者与模型版本。当前验收只确认材料可用，
不以离线检查通过冒充创意质量提高。
