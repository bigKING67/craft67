# Generic adapter

Copy the canonical skill to any agent that supports a SKILL.md-style package and preserve relative references.

The adapter is intentionally documentation-only in `0.2.0`. Use
`../../skills/creative-craft/` as the single source of truth.

The `0.3.1` candidate adds no universal host-compatibility claim. A successful
copy proves only installed-leaf validity; verify discovery and behavior in each
named host.
