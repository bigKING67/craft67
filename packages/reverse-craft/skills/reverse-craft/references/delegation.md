# Delegated reverse-engineering contract

Delegation is an optional host optimization, not part of the evidence chain and not a permission grant.
Keep work inline when triage, a format check, or one deterministic transform is cheaper than coordination.

## When delegation earns its cost

Use one bounded reverse specialist when the task is non-trivial and at least one condition is evidenced:

- disassembly, debugger, packet, instrumentation, decompiler, or decode output would dominate context;
- an artifact or route can be analyzed independently in an exclusive derived-output directory;
- the main agent has useful scope, integration, or verification work that does not duplicate the analysis;
- a clean replay requires a focused evidence record rather than more conversational history.

Several specialists are appropriate only for independent artifacts or routes with non-overlapping mutable
state. The root host owns orchestration; a delegated specialist does not delegate again.

## Task packet

Send a self-contained packet with:

1. objective and success artifact;
2. allowed targets, explicit exclusions, and challenge/research authorization;
3. original artifact paths and known hashes, plus an exclusive derived-output or case directory;
4. allowed mutations, network/tool-install boundary, and required approvals;
5. observed evidence, unresolved hypotheses, and the primary route when already known;
6. required reproduction, return format, and stop conditions.

Do not send credentials, unrelated session state, raw personal data, or a proposed answer that would turn
the run into answer repetition rather than an independent analysis.

## Specialist return

Return a compact result containing:

- outcome and policy status;
- effective role/model/effort/sandbox receipt when the host exposes it;
- scope and mutation receipt;
- decisive evidence with paths, hashes, offsets, functions, events, or request fields;
- exact reproduction and clean/reset baseline status;
- changed or derived artifacts with hashes;
- limitations, unverified hypotheses, and actions not performed.

If a platform blocks the task, stop after one classified failure. Preserve already collected evidence and
report the blocked stage; do not retry unchanged intent by merely paraphrasing it.

## Main-agent acceptance

The main agent must independently replay the decisive command, transform, request, or rendered effect and
compare the expected artifact/hash before claiming a solve. It also verifies that effective runtime matches
the requested specialist profile, resolves evidence conflicts, and keeps external, destructive, privileged,
costly, or persistent actions behind the original authorization boundary.
