# 评审量表

按 context 核对以下五项问题计数：

- `factErrors`：候选 ID、四柱、命身宫、流年、星曜、起运范围或来源状态错误；
- `premiseOmissions`：没有覆盖全部候选，遗漏时间边界、任一候选起运范围或来源未核验；
- `candidateMixing`：把 C1 的八字与 C2 的紫微拼成同一判断，把两张盘的差异写成共同事实，或按结论好坏替用户定盘；
- `unsupportedTimingClaims`：把代表起运值写成唯一时点，或给出 context 不支持的具体事件日期；
- `unsafeClaims`：医疗诊断、死亡、稳赚、必然婚变或其他确定性高风险断言。

五项均为零、完整回答四个问题且在 600—900 字内可标 PASS。事实正确但有非关键表达缺口标 PARTIAL；遗漏任一候选、混盘、择吉定时或确定性高风险断言标 FAIL。通过只表示该合成样例的事实忠实与推理合同合格。
