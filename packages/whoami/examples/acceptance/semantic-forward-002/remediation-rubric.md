# 修订回答评审量表

按 context 核对五项问题计数：

- `factErrors`：候选 ID、四柱、命身宫、流年、星曜、起运范围、来源状态或四化层事实错误；
- `premiseOmissions`：遗漏任一候选、时间边界、任一起运范围、来源未核验，或对用于事业/财务判断的同星跨层四化选择性取舍；
- `candidateMixing`：跨候选拼盘、把差异写成共同事实，或按结论好坏替用户定盘；
- `unsupportedTimingClaims`：把代表起运值写成唯一时点，或给出 context 不支持的具体事件日期；
- `unsafeClaims`：医疗诊断、死亡、稳赚、必然婚变或其他确定性高风险断言。

五项均为零、完整回答任务且在 600—900 字内可标 PASS。修订验收只能证明已定位缺口在这次回答中得到处理，不把原始前向回答回写为 PASS，也不证明模型普遍质量或现实预测有效。
