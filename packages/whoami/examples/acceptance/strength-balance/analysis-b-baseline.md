# 对照 B：乙木日主的普通格旺衰—扶抑局部分析

资料按公历 1987-04-06 18:10、男性、合成东经120度、Asia/Shanghai、真太阳时、子初换日计算。唯一候选盘为丁卯、甲辰、乙酉、乙酉，日主乙木；请求年份为2026、2027、2028。以下仅讨论普通格的强弱、主要负荷和扶抑方向，不作完整人生报告，也不以此推断现实事件。

## 强弱：暂倾向“有条件可任负荷”，不能直接定为身强

支持侧是具体可见的：月干甲为劫财、时干乙为比肩；年支卯与月支辰均有乙木同类根线索，且辰中乙与时干同干透出。这些事实使“无根从弱”不成立为本轮的默认解释。

反证同样具体：日、时两支皆酉，藏辛七杀；年支卯与两个酉均构成直接冲，故卯中乙根不能因为存在就当作稳定有效；辰与两个酉的六合也只是关系线索，不自动认定化局或消除压力。月令司权、卯辰两根的实际等级、酉杀是否实克、甲乙同类能否承担，都没有已核验的作用规则。因此较谨慎的结论是：乙木并非仅凭“有根”即身强，而是**支持显著、但根与杀的作用仍有分歧，暂可讨论为相对可任负荷**。这个结论可被后续根气或制化规则推翻。

依据：`C1-2b3d9d47.bazi.month`、`C1-2b3d9d47.bazi.hour`、`C1-2b3d9d47.bazi.roots`、`C1-2b3d9d47.bazi.rootDetails`、`C1-2b3d9d47.bazi.relations`。相关规则：`C1-2b3d9d47.R-bazi-structure`、`C1-2b3d9d47.R-bazi-root-review`。

## 主要负荷：尚不能单选；优先核验双酉七杀是否形成实际压力

可见的泄身为年干丁食神；而日、时双酉所藏辛均为七杀，且它们直接冲年支卯根。两者不能合并为一个“反对分”：丁的泄与辛杀的克，作用路径不同。就位置和重复结构而言，双酉及其与卯根的冲是本轮更值得优先核验的压力线索；但辛未透干，核心也没有给出杀的实际强度或制化成立的规则，所以不能把它断为已经坐实的“主要负荷”。月支辰中戊财、癸印均未透，也不能凭藏干顺序给财或印排权重。

依据：`C1-2b3d9d47.bazi.year`、`C1-2b3d9d47.bazi.day`、`C1-2b3d9d47.bazi.hour`、`C1-2b3d9d47.bazi.monthExposure`、`C1-2b3d9d47.bazi.relations`。相关规则：`C1-2b3d9d47.R-bazi-structure`、`C1-2b3d9d47.R-bazi-root-review`。

## 扶抑方向：只给分支，不给唯一喜用

若后续核验确认甲乙比劫和卯辰根足以承受双酉压力，且本命的主要偏重确在同类木而非杀克，则可以讨论“食伤火泄比，并需要财星承接”的方向；此盘年干丁食神已提供一条泄秀线索，但财仅藏于辰，是否能承接未证，不能说火越多越好，更不能由此选职业或颜色。

若反过来确认卯根受冲、双酉七杀的作用占主导，日主便转向偏弱分支；此时不应沿用泄木方向，而要先审印星水能否化杀扶身、是否受财制，以及印杀之间是否真能形成该路径。辰中癸只是偏印藏干而未透，故现在也不能把水印宣布为答案。

上述两条路径由“根气与双酉杀的实际作用”这一缺口区分，不是列举所有五行。格局取用、调候取用和普通扶抑取用仍是不同口径；月支辰的财格显干入口在本轮规则模块外，也不能用财格来覆盖扶抑判断。

依据：`C1-2b3d9d47.bazi.year`、`C1-2b3d9d47.bazi.month`、`C1-2b3d9d47.bazi.monthExposure`、`C1-2b3d9d47.bazi.wealthReview`、`C1-2b3d9d47.bazi.rootDetails`。相关规则：`C1-2b3d9d47.R-bazi-structure`、`C1-2b3d9d47.R-bazi-root-review`、`C1-2b3d9d47.R-bazi-wealth-review`。

## 改判条件与限制

- 改为“偏强/比劫偏重”的前提：可核验地确认卯、辰两根及甲乙透干足以任受双酉杀，且双酉的冲、合关系未显著削弱根气；届时才复核食伤泄比、财承接的条件。
- 改为“偏弱/杀为主要负荷”的前提：可核验地确认双酉杀及其冲卯对根气和日主承受能力有决定性作用；届时再审印化杀扶身的实际通路。
- 仍未验证：月令司权、根气等级、冲合能否改写作用、杀印制化、特殊从势/化气、调候规则，以及任何现实职业、关系、健康或财富结果。
