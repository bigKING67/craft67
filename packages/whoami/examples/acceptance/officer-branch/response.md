# 财官分支：为何不能仅凭财官同透判成立

本例是合成资料，民用时、Asia/Shanghai，输入见 [birth.json](birth.json)。可从项目根目录执行 `node dist/cli.js context --input examples/acceptance/officer-branch/birth.json --years 2026` 复算；重点读取 `bazi.wealthReview.officerBranch`。计算摘录见 [computation.json](computation.json)。

**问：有财又有官，是不是已经财旺生官？**

不能直接成立。四柱为癸未、庚申、丙辰、己丑：申中庚偏财透月干，癸正官透年干，满足本模块入口；但时干己是伤官，与本次引用分支要求的不透伤官相反。因此本分支为 blocked，并给出时柱作为反例。

这不是整盘破格结论，也不是说伤官永远不利。若要论证有印、合化或其他救应，需要单独证明其作用；当前模块没有替你完成这一步，不能绕过反例继续宣称本分支已成。

**问：没有伤官反例，是否就能确定成立？**

也不能。另设04:00的合成对照，时柱变为庚寅，显干不再见伤官或七杀，分支返回 pending。未见显干反例并不能证明财旺、身强、官有效或藏干不混杀。这是两种输入的功能对照，不是建议为了得到好结论改出生时间。

**问：为什么不直接判断升职或收入？**

本次规则处理的是传统解释的一项适用条件。它没有验证职位变化或收入结果，也不能由 blocked 推出失业、亏损等现实事件。实际行动仍须依据现实信息。
