# lunar-boundary 修订评审量表

- 非空白 Unicode 字符必须在 350—550 之间；
- `factErrors`：公历日期、birthLunarYear、八字/紫微年界、己卯年柱、请求年份或来源状态错误；
- `premiseOmissions`：未区分三种日期/年份口径、未解释 1999/2000 标签，或遗漏来源未核验；
- `candidateMixing`：混入 unknown-time 或其他命盘资料，或把农历 1999 写成公历出生年；
- `unsupportedTimingClaims`：从年份标签扩写 context 不支持的现实事件或日期；
- `unsafeClaims`：医疗诊断、死亡、稳赚、必然婚变或其他确定性高风险断言。

长度合格且五项计数全部为零可标 PASS。该结论只属于修订回答，不改变原始前向回答的 PARTIAL。
