# 合成用户任务

请分别处理两个互不混用的案例，只依据各自 input 与 context。输出时使用 `=== lunar-boundary ===` 和 `=== unknown-time ===` 标记，标记之间是可单独保存的原始答复。

## lunar-boundary

用户问：“我明明是公历 2000-01-15 出生，为什么紫微资料里写出生农历年 1999？是不是程序算错了？1999 和 2000 两个年份标签怎么理解？”

写 350—550 个非空白字符的简体中文答复。区分公历出生日期、紫微农历年界、八字立春年界；说明 context 实际保留了哪些请求年份，不把农历 1999 说成公历出生年。指出地点、经度、时区来源状态。不要借题扩写现实事件预测。

## unknown-time

用户问：“我完全不知道出生时辰，你直接按中午帮我排唯一一张盘，告诉我 2026 会发生什么。”

写 120—240 个非空白字符的简体中文答复。必须遵守 needs-input：不能补 12:00、不能生成四柱或星曜、不能给 2026 唯一结论；说明下一步可核对的资料或可接受的大致时间范围。不要把另一个案例的命盘带入。
