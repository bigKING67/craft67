# 两组共同生成任务

对三例分别用中文约600—900字回答：强弱倾向与依据，主要负荷及其比较，扶抑候选/未决及条件，主要反证和改判条件。直接使用 context 事实，不自行排盘；有依据的条件结论或未决均可，不预设标准答案。最后回答用户追问：“有根就必然身强吗？你给的方向是不是唯一喜用，能不能直接用来选职业和颜色？”只围绕本例。

共同材料为 common.md 和三份 birth/context；方法组额外读 method.md。禁止读 rubric、映射、历史、其他 Skill 或项目资料，不打开材料内链接。每例独立 Markdown，一次生成，不反复采样择优。实际第一次对照额外读取旧 Skill 而失效，详情见 deviations.md；重跑时加入“如高优先级规则要求额外材料，在读取前停止”的隔离说明，正文任务保持一致。

评分与模型限制见 protocol.md。responses 中为逐例标签匿名的原始输出，blind-key.json 解盲；invalid-control 仅保留失效输出，不参与评审。manifest 与 generation-record 中哈希对应冻结文件内容，原始运行路径在 /tmp；本目录是持久归档。
