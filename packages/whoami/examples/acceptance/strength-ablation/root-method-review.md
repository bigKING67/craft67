# 主代理方法组定向复核（非盲评）

本记录在接收盲评前完成，仅核对生成输出与冻结 facts、method 条件。不是命理专家或现实准确率裁定。

- case-01：四柱与己土的食神辛、劫财戊及藏癸乙映射一致；未丑冲两对与 rootDetails 一致。输出把偏强与比劫偏重、财星承接较轻并列作为食伤分支条件，未把有根直接当强。双辛优先列为待比较泄路，藏财杀仍待核；未完成作用强弱的专家验证。
- case-02：甲寅日、双壬申、寅根受双申冲、巳申合与三刑等与事实一致。庚未透仍纳入申月与冲根比较，未重复上轮“未透所以次要”的直接跳步。杀印通道限定为待核，己财制印反证保留。
- case-03：火根、丁劫财、戊食神、癸官及巳藏庚事实一致。存在一项条件遗漏：方法表中的“日主偏旺，比劫偏重且财轻”，到实际回答变成“若丙火偏强且丁火比劫的偏重得到确认”，末尾再次只写“偏强且比劫偏重”。文中说财未透、承接未证，不能自动代替财轻条件。因候选以条件式表达且否定金越多越好，程度小于无条件断喜用，但仍是本轮需记录的前提缺口。

根气、司权、制化等实际效力仍未验证；这些记录仅证明文字是否保留既定条件，不证明偏强/偏弱标签真实正确。原始输出不修改。
