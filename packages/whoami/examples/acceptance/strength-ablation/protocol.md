2026-09-23。目的：检查新增普通格分析链是否改善条件论证，及此前透藏优先级、可任负荷到泄身的跳步是否再次出现。

## 冻结设计

- 三例出生日期在查看计算结果前选定；两组读取完全相同的 JSON 输入和核心 bazi facts/rules，年份固定2026、2027、2028。均为合成资料，不含真人信息。
- common.md 为现有 analysis.md 的八字部分，移除新 strength-balance 引用段并截去紫微及后续部分；保留既有根气、财格和透干边界。它是消融基线，不是可证明的历史旧版本。
- 方法组额外读取 method.md，即当时的 strength-balance.md 快照；对照组不读取。两组都不打开文内来源链接，不能读取研究、实现、既有样例或评分表。
- 同一中文任务，分别生成每例约600—900字的强弱—负荷—扶抑—转向分析与两项追问。每组仅生成一次，不重采样择优；篇幅超出仅记录，不据此奖励或删除。
- 两名 default 代理 fork_turns=none，未指定模型/推理参数覆盖，请求继承相同宿主配置。没有 effective model、temperature 或 seed 的运行回执，不能声称精确模型版本和采样参数已固定。
- 输出冻结后逐例随机隐藏为 X/Y，映射单独保存，评审只读匿名输出、事实包和预登记 rubric。评审可从文风推测来源，因此只有标签盲化，不保证认知完全盲化。
- 评审逐例给事实、衔接、反证、可用性、范围五项0—2等级及短句依据，单列实质错误。主代理复核裁决并保留任何分歧；不得只用总分宣布胜负。

## 边界

这是三例、一次生成的局部消融试验；没有覆盖完整报告、紫微、多轮自由追问、特殊格、MingLi 题库或 Fatetell。无命理标准答案，观察的是与给定事实及既定条件相符的推理。不能推断统计显著、真实预测准确率、完整 Skill 因果提升或跨模型稳定性。

原始输出保持不变。若本轮根据观察修改 Skill，必须明确原始结果对应修改前快照；该批案例随后变为开发集，不能再作为新版本独立保留集。
