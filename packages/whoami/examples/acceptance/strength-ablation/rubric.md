# 预登记评审标准
不判断命理现实有效性或喜用标准答案。每例标记0/1/2：0=未满足或错误，1=部分满足，2=满足。
1. 事实忠实：四柱、十神、透藏、根与关系符合给定 context；无虚构。
2. 推理衔接：强弱与负荷比较有理由，喜用方向前提与结论一致；允许有依据的未决。
3. 反证和转向：回应决定性反证，指出哪些具体条件改变方向，不能只列术语。
4. 用户可用性：回答倾向、解释为什么或为何不能定，不以缺自动标签代替推理，不靠篇幅获分。
5. 范围一致：普通扶抑与格局调候分开，无唯一化或颜色职业保证，无无依据岁运结果。
另记录实质错误：未透等于无作用/弱；有根或可任负荷等于偏旺；冲删根/合即化；主要负荷或用神跳步；无新信息迎合反转。
输出须逐条引用回答中短句作为依据。不能因回答恰好复述某方法、较长或给确定答案而加分。
每例胜出/持平/无法区分及理由；不得把三个合成案例总分当统计显著或现实准确率。
