# Case 03：丙火日主的局部旺衰与扶抑

**强弱倾向与依据。** 此盘为戊寅、丁巳、丙辰、癸巳，日主丙火。月支巳中藏丙，年支寅与时支巳亦各藏丙；三处均为同干根，且 rootDetails 未列直接六冲。月干丁劫财、月令巳与时支巳又提供火的环境和同类线索，支持日主**偏强候选**。不过“三处根”与“无直接六冲”只是位置及关系筛查，不能折算成确定强度；年支寅与月、时两巳均有害，结构并非完全平顺。时干癸正官、年干戊食神，都是对火的消耗或约束线索。因此是偏强倾向，不以从格为前提。

**主要负荷及比较。** 直接负荷有两类：年干戊食神使火外泄，时干癸正官构成约束；辰中癸与时干癸是同一五行线索的不同位置，不能当作两份独立压力。金只藏两巳为庚偏财，木藏寅甲、辰乙为印，均不可因未透否认，却缺少主导全局的材料。戊、癸比寅巳害更直接构成泄与制；害只能要求复核结构，不预告事件。巳中戊透年干，是月令藏干透出事实，只提供格局讨论线索。财格入口未满足，不能从 outside-scope 断无财格。

**扶抑候选、未决与条件。** 若后续确认巳月、三丙根和丁火确使日主偏强，扶抑可保留土食神的疏泄与水官的约束为候选；其中土、水各承担不同作用，不能合并成一句固定“喜某行”。水若作为季候调节的候选，和以官制身的扶抑理由也应分开。若戊土泄力、癸水约束或寅巳害在具体取法中被证实更重，日主便可能由偏强转中和，此时再加土水未必合适；若火的根与月令支持被否定，木火的扶身才可能进入讨论。没有月令司权、制化有效性与调候细节，就不能给唯一喜用。

**主要反证和改判条件。** 反证偏强的是时干癸官、年干戊食神及两组寅巳害；但它们并不自动推翻火根，也不可从“天干火有两处”单独下结论。改判需核实巳月对丙火的实际权重、三个同干根的有效性、戊是否足以泄、癸是否足以制，以及害在此局中的具体作用。**有根不必然身强**；本例根较多且未列直接六冲，所以偏强的支持较 Case 02 多，但仍不是逻辑必然。土水只是“偏强成立时”的扶抑候选，不是唯一喜用，也不能直接拿来选职业或颜色。职业适配必须由现实技能、偏好、机会和风险评估，颜色仅可按个人审美使用。
