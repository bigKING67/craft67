# Case 02：甲木日主的局部旺衰与扶抑

**强弱倾向与依据。** 此盘为己巳、壬申、甲寅、壬申，日主甲木。月支申是关键环境线索，唯一被列出的同五行根在日支寅，藏甲且与日主同干；月、时两壬偏印透出，提供生扶线索。反面也集中：寅与月、时两申直接相冲，四支又构成寅巳申三刑；申中庚七杀虽未透，却在两处支中出现。因此“日坐寅有根”不能抵销两冲，两壬也不能简单累加为必然扶强。现有事实下，日主取**偏弱候选，置信度低到中等**较合适；不预设从弱或从杀，仍须核对月令、印力和冲刑后的支撑。

**主要负荷及比较。** 最大负荷是申月及双申对寅根的两处冲，且巳、申、寅同时出现三刑；这是需优先核验的压力。庚七杀均藏申，未透，不能说成显杀主导，也不能删除。年干己正财是另一项消耗甲木的可见线索，但其优先级暂低于双申与根受冲。两壬印透月、时，是最重要的平衡线索；巳申六合、巳寅害只说明关系存在，不能由合断吉、由害断凶。财格模块 outside-scope，不能误读成无财或破格。

**扶抑候选、未决与条件。** 如果进一步确认双申当令且寅根受冲后难以充分承载，扶抑可暂保留水印、木比劫为候选：水是否真能生木，要看两壬与申中壬的作用是否受阻；木是否能扶身，也要看寅根的实际效力，而不是只看有一字甲。若核验反而显示两壬得力、寅根虽冲仍可用，甲木可能回到中和，届时不应继续机械增水木，而应重新评估财、杀与泄秀的承受范围。这里没有完成的格局裁定，月令用神、扶抑用神与任何调候说法不能互相替代。

**主要反证和改判条件。** 支持身弱的不是简单“五行数少”，而是月支申、两申冲寅和三刑；反对身弱的也不是重复计算“日支、roots、rootDetails”，而是同一寅甲根事实加上两壬透印。若能证实寅根在该局的有效支持、壬印的转化路径，或相反证实冲刑显著限制其作用，结论都应改判。**有根不必然身强**，本例唯一同干根正受双申冲，尤不可跳步。水木只是偏弱分支下的扶抑候选，不是唯一喜用；若用于职业或颜色会把传统局部解释误作现实能力测量。职业应由经验、技能、收入与环境决定，颜色可按审美选择，不能直接从本例推出。

> 本分析基于传统八字理论框架，仅供文化研究与娱乐参考，不构成职业、投资、婚姻、医疗或法律等决策依据。
