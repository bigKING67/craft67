# 案例 02：甲木

**强弱倾向与依据。**在普通格假设下，甲木暂倾向偏弱，但不是可直接判从弱。日支寅藏甲，是明确的同干根；月、时两干壬偏印透出，且两申均藏壬，构成可讨论的生身通道。反证也很集中：申月对甲木的季节背景不利，月、时两申藏庚七杀，并分别与日支寅直接相冲；同一寅根被两处冲及，不能从资料中直接删除，却也不能仅因“日坐有根”视作稳根。巳、申、寅关系表还列有害、六合与三刑；这些只是结构线索，不足以自动化局、断事或抵销冲根。当前未见能证实从势、专旺或化气的充分条件，故不换用特殊取法。

**主要负荷及比较。**需要优先比较的是两申所藏庚七杀对甲木的压力：它们不透干，却一个在月令、一个在时支，并与寅直接相冲。土财藏于巳、寅、申而仅年干己财明透，火食神只藏巳、寅；因此财耗与食伤泄皆为存在的分支，却不足以在现有事实下取代杀的优先性。两壬偏印也不能被简单当作“水多所以身强”：它们是否能有效化杀生身、是否受己土财牵制以及寅根能否承受，均未裁定。这里的比较结论是“杀为首要待核负荷、印为对应待核通道”，不是已完成的杀印相生。

**扶抑候选、未决与改判条件。**若甲木偏弱且七杀压力为主要失衡，依普通扶抑可优先讨论壬水偏印的化杀、扶身方向；两壬已透，是本盘中已有而非凭空补出的候选。其可用性要以壬水的实际作用、己土财对印的制约及寅根受冲后的承载力为条件，不能说所有水都好。若复核发现两壬足以生扶且寅根受冲未实损，甲木可任杀或转为相对可任负荷，则不应继续以补印为唯一方向，需重比财、食伤和杀的实际力量；反之若冲根与申月压力更重，可再讨论同类木的扶身，但不能把“加木”当自动解法。

**对追问的回答。**有寅中甲根不等于必然身强，本例恰有两申直冲该根，根气的效力须另核。壬水只是“偏弱且杀为主负荷”成立时的扶抑候选，并非唯一喜用，也不能覆盖格局或调候。它不能直接转换为职业或颜色建议；职业应以实际技能、资源、行业与风险承受为依据，颜色没有本分析可验证的决策效力。
