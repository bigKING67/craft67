# 案例 03：丙火

**强弱倾向与依据。**按普通格扶抑，丙火暂倾向偏强、可任一定输出。巳月提供火的季节背景，月支巳和时支巳均藏丙，年支寅也藏丙，三处均是同干通根线索；月干丁劫财明透，进一步构成比劫支持。rootDetails没有列出这三根的直接六冲，支持“未见直接冲”的事实，却不能推出根必稳、身必旺。年寅与月、时两巳均有害，仍是应保留的结构反证，而非足以自动消除火根的结论。没有资料显示从旺、专旺或化气成立，因此这里不以特殊格改变普通扶抑方向。

**主要负荷及比较。**土食神是最明显的泄身通道：年干戊透出，且寅、两巳、日支辰均藏戊；这是一组跨柱的同类线索，不以重复出现相加评分。时干癸正官透出，日支辰藏癸，故水官也构成克火的另一负荷；但它在显干只有一处，现有资料没有把它和巳月、火根的实际作用比较完毕。金财只藏两巳且未透，木印只藏寅甲、辰乙，均不能凭“缺少显干”说没有作用。现阶段较合理的是把食神列为首要已见泄路、把官水列为必须比较的制约，不断言哪一方已压倒日主。

**扶抑候选、未决与改判条件。**若丙火偏强且丁火比劫的偏重得到确认，普通扶抑可讨论先以土食神泄比、再看金财能否承接的方向。土在原局已有多处，故此意不是增加所有土；两巳藏庚只是财承接的条件线索，庚不透且财能否受食神生、会否反使失衡均未证。若进一步发现癸水与辰中癸的制约实际较强，或寅巳害显著改变根气，强火前提会被削弱，应停止把泄火当优先，转而重新比较印比、食伤和官的作用，而非机械改用水或木。调候、格局用神与本段扶抑方向保持分开，财格模块入口外也不构成其他格局的否定。

**对追问的回答。**三处丙根不意味着必然身强；它们尚缺根气等级与寅巳害的实际影响核验，未列直接冲也只是有限事实。土食神、继而金财是“偏强且比劫偏重”前提下的候选，不是唯一喜用，亦不取代调候或格局判断。不能把它直接用于选职业和颜色：职业应基于现实能力、目标、机会与约束，颜色并无本局部分析足以支持的实际决策结论。
