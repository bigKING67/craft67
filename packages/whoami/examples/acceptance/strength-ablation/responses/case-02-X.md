# 案例 02：甲寅日

**强弱倾向与依据。** 日主为甲木，四柱为己巳、壬申、甲寅、壬申。偏弱或受制较明显，是目前较合适的候选：日主同干根只在日支寅；该寅又分别与月、时两申形成直接冲。月、时壬水偏印双透，且申中壬在两处相同位置透出，是能扶持甲木的显著线索；但这不能自动弥补根的受冲，也不能用“两个壬”计成确定强度。相反，申中庚金七杀与戊土偏财均未透出，年干己土正财透出；它们提示财、杀关系需要核验，却不足以单独宣告日主必弱。故结论保留在“身弱/受制倾向”，不采用从弱或从杀等特殊假设。

**主要负荷及比较。** 这例最值得先处理的不是五行缺数，而是寅与两申的重复冲，以及寅巳申三刑的结构线索；再加年寅害、年巳与两申六合，关系并列存在，不能让“有合”抵消“有冲”或反过来。两壬印是显干且与月支藏干精确相合的支持路径；两申中的庚杀则未透，仍可能是月支语境中的压力来源。己财在年干外显，但它相对壬印、申寅冲的实际负荷大小没有权重资料，不能排出固定名次。财格模块 outside-scope，只表示该模块的月令透财入口未满足，不是对财星作用或其他格局的判决。

**扶抑候选、未决与条件。** 如果进一步确认寅根因两冲而难以稳定支持，而壬印能有效生扶，水、木可作为先稳住支持链的扶抑候选：水侧重印的来源，木侧重比劫与根的恢复。这里的“可考虑”以真实强弱和制化有效为前提，不能把壬已双透直接等同为“用水”。若壬水在具体关系中并不形成实质扶持，或甲木实际并非弱，继续增水木就未必合宜；若庚杀的制约被证实突出，则还要另行审查印能否承接，而不能简单以一种元素解决。调候、成格和唯一取用都不在本事实集的自动裁定范围内。

**主要反证和改判条件。** 反证偏弱的核心是：日支寅确实藏甲，且双壬偏印显透；若其支持在实际结构中强于冲的影响，判断可回到中和甚至偏强。反证“杀重”的核心是庚仅藏申、不透干；不能把藏干视为已完成的显性压力。反证“冲即坏”的核心则是资料仅记录直接六冲，没有给出冲后根气的结果。改判需要补足月令实际作用、冲合刑害是否及如何生效，以及各条支持和泄制链的有效性。就本例问“有根是否必然身强”，答案仍是否定：唯一甲根正被两申冲正是缺口。水木只是此分支下的候选，非唯一喜用；它不能直接推出职业或颜色。职业选择应以技能、收入风险、工作环境和个人意愿为准，颜色没有足够依据成为决策规则。
