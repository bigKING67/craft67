# 月令藏干透出：来源、计算与限制

核验日期 2026-09-23。直接阅读《子平真诠》以下三章的原文转录：

- [八、论用神](https://donglishuzhai.net/chapter/3721.html)：月令与日干关系是其讨论出发点，随后仍须结合其余干支；不是只看到某个十神就结束判断。
- [九、论用神成败救应](https://donglishuzhai.net/chapter/3722.html)：格局成败有配合与救应条件，不能由透干单项事实推出。
- [十、论用神变化](https://donglishuzhai.net/chapter/3723.html)：藏干不止一个，透出与其他干支配合影响其格局讨论；应保留并存线索。

来源是古籍正文的现代转录，页面含校勘和后人按语，本轮不将按语当沈氏原文，不宣称完成版本学校勘。另检索到 Wikimedia 的影印 PDF，但工具未提取正文，也未取得足以逐字核对的页面证据，故不把影印本记为已校勘真源。三页 HTML 指纹见 source-manifest.json；不复制全章，不引入站点脚本。传统论述的存在不证明现实预测有效。

## 独立实现的最小规则

输入只使用 whoami 已计算的日主、月支藏干及四柱。对月支每一藏干，精确比较年、月、时的天干，列出匹配柱位；日干同字用 matchesDayMaster 单列。这个字段设计明确区分“日主同字”与“其他干透出”，不宣称为所有流派唯一术语规范。

| 条件 | 计算结果 | 不推导的结论 |
|---|---|---|
| 藏庚，年/时干均庚 | 两个位置分别列出 | 不加两分、不直接判财格成 |
| 藏庚，天干辛 | 庚不因辛而记为透出 | 同金不等于同干 |
| 藏壬，仅日干壬 | 日主同字 true，其他位置为空 | 不把日主作为额外可取用的透干 |
| 多个藏干各自透出 | 全部保留 | 不按频次选择唯一用神 |
| 无其他干同字 | 位置为空，仍保留藏干 | 不等于无根、无格或该五行无作用 |

月令司权、藏干强弱、天干合化、地支会局是否有效、成败救应和特殊格均不由该联结自动裁定。用神的月令格局语境与调候、扶抑语境必须分别论证。

## 可复算样例与反例

examples/birth.json 的四柱为庚辰、甲申、丙午、庚寅。申藏庚壬戊，相对丙日主分别为偏财、七杀、食神。庚在年、时透出，壬戊没有在年/月/时透出；这为财的格局候选提供线索，尚不证明格局成立。

tests/evidence.test.ts 覆盖此合成出生样例，以及同五行异干、多个藏干并存、日干单列、候选隔离。人工修改盘面 fixture 仅用于事实联结反例，不当成可实际出生的历法样例。所有结论应通过 context 与 report-check 追溯。
