# 八字岁运目标章节页级外交转录

核验日期：2026-09-26。机器可读正文见 [bazi-timing-diplomatic-transcription.json](bazi-timing-diplomatic-transcription.json)，逐栏回查见[坐标与局部影像定位](bazi-timing-column-locators.md)及其[机器可读坐标](bazi-timing-column-locators.json)，局部版本关系见[证据矩阵](bazi-timing-stemma-matrix.md)。本底稿覆盖五个扫描见证、28 个 PDF 页或跨页，范围是《子平真诠》的“论行运”“论行运成格变格”“论支中喜忌逢运透清”和《滴天髓》的“岁运论”。

这里的“页级外交转录”指：保留各见证实际印出的字、标点、章节与注层标签、缺文标记、页或叶面边界，并按传统竖排自右向左的次序转成连续文本。它没有模拟原书逐栏换行或字形，也没有把疑字改成通顺句，因此不是影印替代物、规范化定本或完整版本谱系。

## 新增的实质发现

这轮逐字复核推翻或补充了上一轮两处概括；随后逐栏复核又纠正了一处页界误判：

1. 1926 本“若命与运二支会局”后清楚印作“亦作清出”，世界图书馆本作“亦作清论”。“清出”句法可疑，却是该见证可见读法，不能因为后本更通顺就替换。
2. 明末本“何为和”清楚印作“喜水則甚利”，1936 本与 1947“原注”作“喜水则不吉”。两支解释方向相反，是会改变规则方向的实质异文，不能合并成自动规则。
3. 页级初稿曾误把明末本 PDF 第 68 页右叶“喜陰則”标成无标记中断。逐栏回看证明，左叶最右栏续印“辛與酉為好。此皆宜例推以見。”，再下一栏才进入“貞元”。这不是跨版本补文，而是同一扫描页的跨叶连续正文；机器底稿现已恢复该栏并撤销中断标记。

另有数处可见但句法可疑的早期读法，例如明末本的“主譬如吾身”“大。則運自降。吉。”以及 1947 本命例中的“是年進而中”。底稿保留所见字面，同时明确禁止用这些句子单独支持规则结论；三处现已进入[来源隐藏盲审包](bazi-timing-blind-review/README.md)，外部独立复核尚未发生。

## 使用合同

引用时至少携带 `witness + pdfPage/printedPage + layer + completeness`。`text` 是该页或叶面的转录；`boundaryNote` 说明章界；`lacuna` 是书内明印缺文；跨叶正文必须按 `parts` 的阅读次序连续读取；`chart` 是 1947 任氏命例版面中的四柱与大运，不是经本仓库重新排盘得到的数据。

本轮仍不修改 TypeScript、cycles、报告 schema、`R-bazi-timing` 或 evidenceId。新的异文证据进一步说明：战、冲、和、好、透清或盖头截脚都不能仅凭标签映射成固定吉凶、分值、年份排序或现实事件。工程层继续只吸收版本、层次、缺文和条件链的约束。
