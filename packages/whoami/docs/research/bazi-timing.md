# 八字岁运：来源、反例与吸收边界

核验日期：2026-09-26。结论：现有 `R-bazi-timing` 的“冲不等于灾、合不等于吉”方向与所读文本相容，但原先只有一句内部指导，不能说明为什么必须先定本命前提、逐干逐支回配，也没有显露成格/变格和同类冲合的反例。本轮补齐来源与运行步骤，只吸收论证顺序和失败条件，不生成固定吉凶规则、权重或事件日程。

## 来源与版本限制

本轮先读取以下公开转录，再用五个公开扫描本核对关键段落；页面与 PDF 指纹、字节数和定位语见 [source-manifest](source-manifest.json)，段落级机器可读对照见[整章校本数据](bazi-timing-collation.json)：

1. [《子平真诠·论行运》](https://donglishuzhai.net/chapter/3738.html)：要求运的干支回配本命整体，并连续列出“似喜实忌”、干支同类而作用不同、冲的轻重缓急及“逢冲而不冲”等反例。
2. [《子平真诠·论行运成格变格》](https://donglishuzhai.net/chapter/3739.html)：说明运可补成本命结构或改变结构，同时明列“成格而不喜”“变格而不忌”，不能看到成格/变格标签就直接定吉凶。
3. [《子平真诠·论支中喜忌逢运透清》](https://donglishuzhai.net/chapter/3741.html)：强调逐干逐支、上下统看，并把取运继续放回本命八字逐项配合；不支持按五行名称或透藏次数直接评分。
4. [《滴天髓·岁运论》页面转录](https://zh.wikisource.org/zh-hant/%E6%BB%B4%E5%A4%A9%E9%AB%93/09)：把岁运的冲、战、和、好放在日主与全局喜忌中讨论；同一合化示例会随所喜不同而改变判断，因此“合”本身不是吉的标签。该页面没有标清原文、原注和后世评注，不能整体视为同一作者层。
5. [《三命通会》四库全书本卷十一](https://zh.wikisource.org/zh-hant/%E4%B8%89%E5%91%BD%E9%80%9A%E6%9C%83_(%E5%9B%9B%E5%BA%AB%E5%85%A8%E6%9B%B8%E6%9C%AC)/%E5%8D%B711)：以日干、月支、四时消长和运对八字的助、泄、克、生为联读入口，也说明通常被称为吉或凶的因素仍受损伤、制伏、去留与合化改变。

### 多版本扫描本定点校勘

- [国家图书馆藏世界图书馆本《子平真诠》](https://commons.wikimedia.org/wiki/File:NLC416-11jh010455-35296_%E5%AD%90%E5%B9%B3%E7%9C%9F%E8%A9%AE.pdf) PDF 第 56—62 页、书页第 47—53 页完整保存“论行运”“论行运成格变格”“论支中喜忌逢运透清”；“论行运”首句作“配命中八字之喜忌”。[1926 年文明书局、秦慎安校勘本第 2 卷](https://commons.wikimedia.org/wiki/File:NLC416-13jh002326-46443_%E6%B7%B5%E6%B5%B7%E5%AD%90%E5%B9%B3_%E5%AD%90%E5%B9%B3%E7%9C%9F%E8%A9%AE_%E7%AC%AC2%E5%8D%B7.pdf) PDF 第 43—46 页、书页第 30—33 页完整保存第一、第三章；第二章在 PDF 第 45 页、书页第 32 页只到“壬生戌下阙”，随后直接跳到第三章，所以它不是第二章的完整见证。1926 本首句作“配八字之喜忌”，同页稍后仍有“配命中八字而统观之”。东里书斋首句与 1926 本相合，所以“命中”是版本异文；网页的“校”“按”区继续视为编辑层，不能静默回写扫描正文。
- [明末长庚馆刊本《滴天髓》](https://commons.wikimedia.org/wiki/File:NCL-06619_%E6%96%B0%E9%8D%A5%E8%AA%A0%E6%84%8F%E4%BC%AF%E7%A7%98%E6%8E%88%E7%8E%84%E5%BE%B9%E9%80%9A%E6%97%A8%E6%BB%B4%E5%A4%A9%E9%AB%93.pdf) PDF 第 66 页右叶开始“岁运论”，核心句作“战冲视其孰降”，随后已有“何为战、冲、和、好”例解，至 PDF 第 68 页左叶最右栏结束，再下一栏进入“贞元”；[上海大东书局 1947 年《滴天髓阐微》](https://commons.wikimedia.org/wiki/File:SSID-11335994_%E6%BB%B4%E5%A4%A9%E9%AB%93%E9%97%A1%E5%BE%AE.pdf) PDF 第 501—511 页、书页第 113—123 页同样作“战冲”，并在 PDF 第 502 页、书页第 114 页明确分列核心句、`原注` 与 `任氏曰`。[1936 年乾乾书社《滴天髓辑要》](https://commons.wikimedia.org/wiki/File:NLC416-01jh000040-9444_%E6%BB%B4%E5%A4%A9%E9%AB%93%E8%BC%AF%E8%A6%81.pdf) PDF 第 25—27 页、书页第 20—22 页则作“衝戰”，与维基文库页面相合。因此“战冲/冲战”是至少两个扫描版本分支，不是可以仅凭一个版本裁定的转录错误。
- 明末本已经包含战、冲、和、好的原注式例解，1947 本把对应层标为原注，并另加、明确标出任氏评注；1936 辑要本还含括注，例如“乙庚化金”“子丑合而化土”，这些括注在明末本与 1947 原注层不见。维基文库连续收录与 1936 本相合的括注，却没有完整标出来源层，适合作检索和交叉检查，不能单独充当逐字底本或作者归属证据。

## 跨来源共同边界

| 可吸收的窄结论 | 依据 | 不能据此推出 |
|---|---|---|
| 运、岁必须回配本命，不能脱离本命取法单看年柱或运柱 | 《子平真诠》论行运与逐干逐支段；《三命通会》日干、月支及四时入口 | 某干支对所有命盘都有固定吉凶 |
| 天干、地支及相同五行不能合并成一个抽象分数 | 《子平真诠》分别列出行干不行支、行支不行干及同类不同作用 | 五行同类即可加分，出现次数即可排序 |
| 冲、合、成格、变格都需要检查原局配置与反例 | 《子平真诠》冲的轻重/失效及成格不喜、变格不忌；《滴天髓》岁运冲战和好 | 冲必凶、合必吉、成格必吉、变格必凶 |
| 大运和流年是不同层，但没有统一、可直接编码的绝对权重 | 《滴天髓》分别比拟大运与太岁并继续要求全局胜负适从；其他来源按各自格局展开 | “大运占七成、流年占三成”或任何固定比例 |
| 支中所藏被运引出可形成一个传统解释入口 | 《子平真诠》透清与逐干逐支段 | 藏干一透就一定应事，或透出本身证明现实结果 |

## 当前吸收决策

运行时采用 [八字岁运联读](../../references/bazi-timing.md) 的六步检查：本命前提、大运层、流年层、主题成立路径、替代路径/反例、现实资料。它落实的是来源共同支持的论证顺序，并明确三类证据：核心可复算事实、宿主传统解释、可追踪但不自动可信的现实资料。

本轮不修改 `.bazi.cycles`、报告 schema、evidenceId 或 `R-bazi-timing` 的事实引用。原因是所读来源没有给出足以自动判定作用强度、成败或现实事件的统一算法；把文本转成新评分会比现有人工条件性论证更武断。原典中的人物、富贵、灾祸和应年也不进入测试真值。

可验证的改进是：Skill 在遇到八字大运或流年问题时必须加载运行参考；分析契约把逐层回配和反例检查列为必经步骤；研究索引、来源清单、整章校本与坐标层保存读取范围、扫描页码、段落完整性、版本异文、文本层次、栏位及指纹。下一阶段若要引入自动规则，至少还需要版本谱系、流派范围、正反命例盲核和能区分替代解释的验收，不能仅凭本次文字校勘升级。
