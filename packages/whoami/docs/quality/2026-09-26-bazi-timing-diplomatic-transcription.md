## 验收边界

扫描页是字面结论的权威证据；OCR 和公开转录仅用于定位。逐页人工检查采用 300 DPI 渲染，并对难辨位置再次放大。页级转录本身保留页界与阅读顺序，但不模拟逐栏换行、字模差异、版心、书口或手写题记；后续独立的[逐栏坐标层](2026-09-26-bazi-timing-column-locators.md)增加导航框和局部证据图，仍不声称完成可替代影印的字形级摹本。

1926 本“壬生戌下阙”仍是显式缺文，没有从其他见证补齐。逐栏复核纠正了明末本 PDF 第 68 页的页界误判：右叶“喜陰則”续左叶最右栏“辛與酉為好。此皆宜例推以見。”，其后才进入“貞元”。1947 本“原注”“任氏曰”和命例维持独立块，1936 括注也没有回写到明末或 1947 原注层。

## 校正结果

本轮对上一轮校本作两项证据性修正：新增 1926“亦作清出”异文；把明末“喜水则甚利”与后本“不吉”登记为方向相反的版本支。随后逐栏坐标复核撤销了页级初稿对明末本“喜阴则”的中断判断，并恢复同页左叶的连续正文。这些修正只影响文本证据和引用合同，不产生运行时算法变更。

验证要求：两个 JSON 必须可解析；见证数、页面数、章节数、显式缺文和跨叶连续正文须与底稿摘要相符；仓库文档链接须无缺失；`npm run check` 仍须通过。测试通过只证明工程和文本产物可复核，不证明古籍理论、命例叙述或现实预测有效。
