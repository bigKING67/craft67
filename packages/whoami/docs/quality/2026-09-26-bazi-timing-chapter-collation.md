## 纠正与新增发现

第一，1926《子平真诠》不能再概括为“完整覆盖三个目标章节”。PDF 第 45 页、书页第 32 页在“何谓变格”段明印“壬生戌下阙”，随后直接进入“论支中喜忌逢运透清”，中间“论喜忌干支有别”也不见。校本将后续三段标为 `absent-in-witness`，没有从世界图书馆本或网页静默补齐。

第二，《子平真诠》除“命中”首句外，还确认“冲时日/冲日时”“于外格/于各格”“命中原有/柱中原有”“支以为干/支为干”等差异；东里页面对“身轻”移位及巳/丑、申/生、外/各的校改均继续保留为编辑层。这些差异可以影响引用文字和层次，却没有改变当前“回配本命、干支分看、保留反例”的运行顺序。

第三，《滴天髓》1936 本的括注不是明末本早期例解或 1947 原注层的共有文字。“乙庚化金”“子丑合而化土”等括注与维基文库页面相合，但在明末本和 1947 原注层不见；1947 本另以 `任氏曰` 展开总评、盖头截脚、战冲和好解释及命例。因此维基文库不能把连续显示的文字整体归给同一层。

第四，1947《滴天髓阐微》的精确边界也得到修正：PDF 第 511 页、书页第 123 页在任氏释“好”结束后已经进入“贞元”，并非到第 512 页才开始。

## 方法与限制

扫描页按 300 DPI 渲染，繁体竖排 OCR 只用于寻找段落；缺文、异文和层次结论均回到扫描页目视确认。底稿采用段落完整覆盖和实质异文粒度，没有声称完成逐字外交转录。字体、标点、通假、所有单字小异和版式未穷尽；版本谱系、作者归属与唯一正字仍未裁定。

本轮只修改研究、来源和质量文档，不修改 TypeScript、依赖、cycles、报告 schema、`R-bazi-timing`、evidenceId 或冻结报告。新证据支持增加引用约束：古籍引用必须带 witness、locator、layer、completeness；显式缺文不得跨版本静默补齐；编辑括注不得冒充早期正文。它不支持新增固定权重、自动吉凶、年份排名或现实事件预测。

## 验证结果

机器底稿结构校验 PASS：7 个见证、4 个章节和 35 个段落 ID 均唯一；所有 coverage/locator 都指向已登记见证；12 个 `aligned` 与 23 个差异段合计 35；5 个扫描见证的 SHA-256 在 42 项来源清单中各唯一出现一次；决策仍为 `runtimeChange=false`。5 份本地 PDF 的 SHA-256、字节数和页数逐项匹配来源清单。

`npm run check` 为 185/185 PASS，TypeScript strict 与 build PASS；24 份 semantic-forward manifest 由当前构建版逐份重放并全部保持 partial；Skill quick_validate PASS。`full-1991` 的 2026—2028 context 保持 chartId `3f46b10f2f63940f5b589531a6cd9a4866c904062a8580dc1ae843cd59c7786a`、evidenceId `eaf468fb8c1a63f9440e51743c82d658fc71a2021293243a2082393f734c0bce`，`report-check` 返回 valid，birth、report JSON、report Markdown 和 premise review 四项收据哈希一致。

最终文档范围为 93 个 Markdown、451 个本地链接且零缺失；private、node_modules、tmp 和 `.git` 之外 183 个 JSON 全部可解析。`openspec/` 与 `.git/` 均不存在。以上验证证明校本结构、来源指纹和既有工程行为没有漂移，不证明文本存在唯一正确版本、传统理论成立或现实预测有效。
