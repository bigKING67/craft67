# 八字岁运版本关系证据矩阵验收

日期：2026-09-26。目标：把既有异文、外交转录和逐栏锚点组织成可审计的同书版本关系矩阵，识别分支信号、缺文、后加层和网页混编，同时阻止局部相同被误写成直接抄传关系。

## 交付

- [版本关系说明](../research/bazi-timing-stemma-matrix.md)
- [机器可读矩阵](../research/bazi-timing-stemma-matrix.json)
- 上游证据：[实质异文校本](../research/bazi-timing-collation.json)、[外交转录](../research/bazi-timing-diplomatic-transcription.json)、[逐栏坐标](../research/bazi-timing-column-locators.json)

矩阵覆盖 2 部书、5 个扫描见证、2 个网页参考节点、16 个鉴别特征和 9 组同书两两关系。所有关系均保存 `directionality`；直接传承边数为 0。

## 验收边界

- 只比较同书、同一鉴别特征；缺失或本轮未核状态不计作相同或分歧。
- 不生成数值相似度，因为特征集是有意选择的差异点，不代表全书字符分布。
- 扫描见证、网页转录、现代校记、括注、原注和任氏层必须保持不同节点或状态。
- 共享读法只能支持“局部兼容”；没有独立书志证据时，不允许生成父本—子本箭头、唯一底本或作者归属。
- 明末本 PDF 第 68 页按已更正的跨叶连续正文进入矩阵，不得恢复“喜阴则中断”的旧误判。

验证门槛：矩阵 JSON 与仓库 JSON 可解析；摘要计数与对象实际数量一致；所有特征状态仅引用本书节点；9 组关系不重复且只引用存在的特征；`evidenceRefs` 能解析到校本 segment 或逐栏 anchor；直接传承边保持为空；相关文档链接无缺失；`npm run check` 通过。

## 验证结果

- `PASS`：矩阵实际包含 2 部书、5 个扫描见证、2 个网页参考节点、16 个鉴别特征和完整的 9 组同书两两关系。
- `PASS`：全部节点、特征状态、关系分组和方向字段有效；相同、分歧、缺失、层差及未核特征没有在同一关系中重复归类。
- `PASS`：16 个特征的 `evidenceRefs` 均能解析到 35 个既有校本 segment 或 10 个逐栏 anchor；三个上游机器产物均反向登记本矩阵。
- `PASS`：两部书的 `directDescentEdges` 均为空，摘要中的直接传承边为 0；没有生成数值相似度。
- `PASS`：非临时、非 `private`、非依赖目录的 186 个 JSON 均可解析。
- `PASS`：本轮 7 个 Markdown 的 73 个本地链接无缺失。
- `PASS`：`npm run check`；TypeScript typecheck、185/185 tests 与 build 全部通过。

矩阵通过只能证明版本关系陈述受现有文本证据约束，不能证明命理理论、古籍命例或现实预测有效。
