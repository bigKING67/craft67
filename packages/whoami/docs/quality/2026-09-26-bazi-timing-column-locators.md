## 验收边界

Tesseract 只提供版面几何，未把 OCR 字符写进正式转录。`verticalLineRegions` 是回查候选，不声称字形级框选或排字栏绝对复原；关键读法以手工检查的扫描和局部证据图为准。局部图也不是源 PDF 的替代物，引用仍须携带见证、PDF 页、书页或叶面、文本层和完整性。

验证门槛：坐标 JSON 与其余仓库 JSON 可解析；页面、叶面、区域、锚点及证据图计数相符；所有框在页面范围内；栏位按右至左排序；证据文件存在且大小、尺寸、SHA-256 与登记值一致；十个锚点均指向存在的栏位；五个源 PDF 指纹保持一致；本轮文档本地链接无缺失；`npm run check` 通过。
