# 八字岁运联读

本参考只约束大运、流年如何回配本命及如何表达不确定性，不提供固定吉凶表、年度评分或事件预测算法。年份、干支、起运范围和立春边界以当前 context 的 `.bazi.cycles` 为事实来源；传统解释仍由宿主逐项论证。

## 前置条件

1. 固定出生候选、问题主题、报告时区和明确年份；时间表达与 evidence 粒度先通过 [时间契约](time.md)。
2. 先完成当前候选的旺衰、格局、调候、扶抑与最终取舍。`bazi-timing` 可以引用这些已经写出的条件，不能在运年段暗中重判本命，也不能把 unresolved 前提当成既定喜忌。
3. 从 `.bazi.cycles` 读取实际大运段、逐年干支和立春边界。起运状态为 range 时，保留范围及可能跨段的分支，不以代表值替代确认值。
4. evidence v2 的 `.bazi.cycleRelations` 逐年给出立春区间、该流年内生效的大运（`decadeStatus`：single / switches-within-year / first-decade-starts-within-year / last-decade-ends-within-year / start-uncertain / before-first-decade / after-last-decade，及每步运的 coverage；起运为 range 且当年有非全年覆盖的运时一律 start-uncertain），以及“流年-本命”“大运-本命”“流年-大运”的天干五合与相冲、地支冲合刑害与自刑、伏吟反吟；须岁运补齐（本命已完整的不重复列出）的三合、三刑、三会分为“大运-本命组合”（整步大运内都成立，不是当年新触发）与“流年参与组合”（须当年流年补齐）。`decade-N` 位置对应 `decades[]` 中同 index 的一步运，其 coverage 说明该步运在当年是否全年生效。天干冲只取甲庚、乙辛、丙壬、丁癸四冲，戊己居中不论冲。地支成对关系含冲、六合、害、刑（子卯及寅巳申、丑戌未组内两两）、自刑、半合（含旺支）、拱合（生墓）与破；本命 relations 在 v2 使用同一张表并加三会。引用这些关系时直接取此事实并纳入 bazi-timing 依据，不自行重算；未列出的组合不等于无作用，列出的组合也只说明关系出现，不说明合化成败、冲是否成立或现实结果。年内换运或起运不确定时，按各步运分别论证，不合并成单一大运。

## 流月（仅月度 evidence）

`--granularity month` 时 `.bazi.monthlyCycles` 逐年给出按节切分的 12 个流月：月柱、起止节名（startJie/endJie）与时刻（+08:00）、窗口内大运（decadeStatus 以 -month 结尾），“流月-本命”“流月-流年”“流月-大运”的成对关系，以及须由流月补齐的“流月参与组合”（三合、三刑、三会）。流月是叠加在本命、大运与流年之上的最弱一层：先说明该年、该运的判断，再说明流月如何加强、削弱或只是重复已有关系；不能只凭流月关系断事，也不能把节气月改写成公历月。正文写“八字流月<干支>”时须引用 monthlyCycles 并绑定同候选 bazi-timing。

## 逐年论证顺序

以下六步是完整档 `annualReviews` 的写作顺序。快速档可压缩表达，但每年仍须说明所依本命前提、所在大运与主要关系、成立与替代路径；交运、立春等周期边界日期可作为事实陈述，不能据此给出月日级事件判断。

每个 `annualReviews` 项按以下顺序写作，缺一项就把缺口留在 `missingLinks`：

1. **本命前提**：说明本年沿用哪一种本命取法、其状态和撤回条件。喜忌、格局或强弱仍未定时，年度方向也保持分支。
2. **大运层**：指出该年实际所在大运及其干支。只记录进入哪一步运不等于该运已吉或已凶。
3. **流年层**：分别核对流年天干、地支与本命各柱及当前大运的直接关系。相同五行、相同干支、冲、合、刑、害都只是作用入口；不能把关系名称直接翻译成结果。
4. **成立路径**：说明哪条本命前提、哪一层岁运关系及什么现实条件共同支持当前主题。事业、财富、关系等现实主题必须分别论证，不能共用一个年度标签。
5. **替代路径与反例**：至少检查同类干支但作用不同、冲合被其他结构改变、成格而不喜、变格而不忌，以及本命取法本身改变的可能性。没有定位到具体反例时，说明尚缺哪项事实，不能写“已排除所有反例”。
6. **现实资料**：用户经历只记录为来源可追踪的复核入口。没有事前记录、独立核验及可区分的替代解释时，不把事后相符写成命中，也不据一次反馈外推其他年份。

## 证据与措辞

把内容明确分成三层：

- **可复算事实**：本命四柱、relations、大运段、年度干支、立春边界、cycleRelations。
- **传统解释**：基于当前取法提出的作用路径、反例、适用范围和撤回条件。它是条件性论证，不是核心计算事实。
- **现实资料**：用户或外部来源提供的经历与条件；标明来源和核验状态，不反向改写命盘事实。

以下写法不能由当前证据推出：

- 仅因冲而断灾、因合而断吉，或因同干同支给年份加分；
- 把大运、流年任一层单独当作最终结论，或声明固定的“大运管十年、流年决定当年”权重公式；
- 从年序生成“准备—爆发—收获”等行动日程，给年度排一二三或输出概率；
- 将传统文本中的富贵、灾祸或历史命例当成现实有效性证据；
- 用用户事后反馈补写为事前预测，或用一个年份证明相邻年份同样成立。

## 状态与交付

默认状态是 unresolved。只有本命取法、大运与流年作用、主题映射、关键反例和现实条件都在当前范围内闭合，且 `missingLinks` 为空，才可收窄为 conditional；conditional 仍不表示事件必然发生或发生概率已知。

正文只回答用户所问主题。能够确认的先给出，不能确认的说明卡在哪一层以及什么资料会改变判断。低风险建议可依据现实条件给出，但不得包装成命盘指定的年份窗口。传统来源、版本限制和本项目的吸收决策见 [岁运来源审计](../docs/research/bazi-timing.md)。
