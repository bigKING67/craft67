# 普通格：旺衰到扶抑的条件性论证

用途：用户需要强弱倾向、扶抑取用或追问喜忌时读取。以已计算的本命事实形成可检验的传统解释；这不是数值评分器，不计算现实发生概率，也不是完整格局/调候规则。

## 采用的取法与来源

本轮以《滴天髓阐微》“体用”篇任氏注的普通扶抑取法为主：根据日主承受能力和具体失衡选择方向，并保留旺极、弱极等改变取法的例外。用《子平真诠·论十干得时不旺失时不弱》复核“月令不是唯一依据、根与透干不能简单计数”的前提。两份来源的作者与用神语境不同，不宣称是一套原书算法，也不把月令格局用神等同扶抑用神。

来源与边界详见[研究记录](../docs/research/strength-balance.md)。下面的组织流程是whoami的工作约定；原文没有提供统一权重或机器判定阈值。

## 1. 先限定普通格假设

明确采用普通格扶抑假设，并复核是否有需要另论的从势、专旺、化气等迹象。不能因无同五行根就认从弱，或因印比多就认专旺；化气也不能仅凭天干相合成立。如果特殊取法可能改变本次方向，说明具体依据，暂停普通格的最终取舍，保留两条有条件的路径。不要把“特殊格尚未自动检测”当作所有命盘都无法讨论的理由。

## 2. 建立同一候选的支持与反证

按事实位置和作用解释，不给加减分：

- 月令背景：说明季节及月支藏干怎样支持或限制日主，不能把得令直接等同全局强、失令直接等同弱。辰戌丑未的藏气并存不能简化为“土月所以土必强”。若判断依赖具体司权日数而当前资料没有提供，指出这项依赖。
- 支持侧：逐个指出同五行根、印比的透藏位置；本气/余气等分级若采用，另给其来源，不从藏干数组顺序猜权重。日干不当作额外比肩证据，同一根的多个事实ID不重复计权。
- 负荷侧：具体指出食伤的泄、财的耗、官杀的克分别在哪里、是否透出及有无根气线索。出现不等于有效作用，不能把三类作用合并成一个“反对分”。比较主要负荷时，透干不能单独压过月令藏气的作用；未透也不等于弱或不作用。若只确认一项透出、尚未比较另一项得令的作用，只能将其列为待比较分支，不能给出优先级。
- 关系与反证：核对根所受冲、合化前提及可能制化。受冲不自动删除根，无冲不自动证明根稳定；原始关系表不保证涵盖所有流派关系，影响结论的缺项需明确。

最后给出“暂倾向偏强/偏弱/相对可任负荷/两种读法仍不能取舍”等**传统条件性判断**，写出倾向某一分支的比较理由。不要只复述“有根、有印、未自动裁定”。核心未提供最终标签，不妨碍宿主在证据支持下作conditional论证；反过来，字段齐全也不强迫宿主定强弱。

### 可以先收窄的两类最低结论

以下结论只收窄分析范围，不替代最终旺衰或用神判断：

1. **支持基础已见**：同一候选至少有一处日主同五行根未见直接六冲，并另见可定位的印比透藏时，可以条件性写“并非无根，存在支持基础”。同时列出受冲根、失令、泄耗克等反证。该结论不等于身强、偏强、可任全部负荷，也不能用未见直接六冲证明根气稳定。
2. **某类负荷应优先比较**：月支所藏食伤、财或官杀之干至少一处同干透于年、月、时，且排除月支来源及用于证明透出的柱位后，另一柱位仍有同类负荷可定位于透干或藏干时，可以把该负荷列为本轮优先比较分支。例如月令庚偏财透年干，时干又见庚偏财，可写“财荷相对根印支持须优先比较”。这不等于财旺、财为主要负荷、日主偏弱或现实财运结论；同源事实不得重复计权，其他得令或未透作用仍须比较。

第一项的两个条件必须同时成立：“未见直接六冲的同类根”与“额外可定位的印比支持”不能互相替代。日干本身不算额外比肩；用于满足根条件的同一藏干即使同时标为比肩或劫财，也不能再算第二份支持。只有受冲根而另有印，或只有未冲根而没有独立印比线索，都不足以由这条最低规则把 strength 改为 conditional；此时只保留已见事实与改判条件，也不能反向写成身弱。

第二项同样是合取条件。条件 A 是 `monthExposure` 对某个负荷干给出至少一个 `exposedAt`；条件 B 是在月支及选作 A 的透干柱位之外，另一柱位再见同类负荷。这里的同类只分为食神/伤官、正财/偏财、正官/七杀三组；正偏可以归入同一负荷比较，但必须保留各自身份。一个透干不能同时满足 A 和 B，同一柱的透藏也不拆成两个柱位。只有其他柱藏同类负荷而月藏原干未透，或月藏原干只透一处而没有另一柱同类负荷，都不足以由本条把 balance 改为 conditional；也不能反向推出该负荷很轻、日主很强或另一负荷占优。

只有最低结论本身及其限制已有事实支持时，strength 或 balance 才可标为 conditional。若正文实际仍只说“字段已列、无法判断”，继续用 unresolved。最低结论与最终强弱分开：前者回答“哪些支持或负荷已经不能忽略”，后者仍须解释这些作用为何足以占优。

## 3. 从具体失衡选择扶抑方向

先说明失衡是什么，再讨论用什么解决。下表是来源中的条件分支，不是见到某十神就触发的规则：

| 已论证的前提 | 可优先讨论的方向 | 本次必须核对的反证 |
|---|---|---|
| 日主偏弱，主要负荷为官杀 | 印绶的化生与扶身 | 印是否存在且能作用，财是否制印，官杀与印之间是否真的能形成该路径 |
| 日主偏弱，主要负荷为食伤 | 印绶的制泄与扶身 | 食伤是否确为主要负荷，印是否受财制，根印能否支撑普通格假设 |
| 日主偏弱，主要负荷为财 | 比劫的帮身任财 | 比劫是否实际可用，新增比劫对财的争夺及其他格局要求，不得自动说越多越好 |
| 日主偏旺，印绶构成主要偏重 | 财星的制印方向 | 财是否能用、位置与制化是否成立，不能把财印相邻风险直接当作问题已解决 |
| 日主偏旺，比劫偏重且财轻 | 食伤泄比并接续财的方向 | 食伤是否可用、印对食伤的制约、食伤与官杀的作用及财的承接分别核验 |

未确认强弱或主要负荷时，不按这张表硬选。可以给“若A成立则讨论X，若B成立则改看Y”，但必须说明哪个事实或规则分歧决定转向，避免无穷列举所有元素。 使用某一行时须保留该行的全部前提；提出条件候选也要写全尚待成立的条件。例如“可任负荷”不等于“偏旺”，“比劫偏重”也不能替代“财轻”；财未透本身不能证明财轻。

### 财轻与食伤生财的窄复核

本表的“财轻”是普通扶抑中财相对于已论证的日主、比劫之势偏轻，不是透干数量标签。先列财的确切透藏位置及同五行支持，再比较月令背景、食伤生源、比劫克财与其他作用；解释哪一侧依据使财相对偏轻，并给出反证。财藏而未透、财只一位、财格模块入口外，都不能单独证明财轻；藏干顺序也不是强度。rootDetails仅列日主同五行根，财的支持须另查各柱藏干，不能拿该列表判断财有无根。若作用尚不能比较，写“财轻待核”，候选条件须保留此项。本段是项目整理的论证清单，来源未给出统一阈值。

“食伤能泄身”“五行上能生财”“本盘财能承接且此通道可用”是三层判断。逐个指明食神/伤官、正财/偏财的柱位，以及财的支持、印对食伤的制约、比劫对财的争夺及官杀是否改变当前取法。只有十神共现或五行相生时，可说存在候选路径，不称通关、生财已有效；也不由相邻、隔位直接认定畅通。

普通扶抑与《子平真诠》的财格分支分开：论财章的财格用食神讨论身强及不露官等前提，成败救应章的对应组合另列身强带比，须标明引用哪一分支；财格用伤官讨论财不甚旺、比强等另一组条件。食神不能代替伤官，正官不能代替七杀，不能把财格的“不露官”移成所有扶抑取法的禁令。出现印也不直接断食神被毁：原文另论食印不相碍、暗官改变取法等分支，需说明位置与实际作用。采用哪个分支，就完整核验该分支，不拼接别的段落补成成立。

来源、注释层级及未覆盖项见[财轻与承接研究](../docs/research/strength-balance.md#财轻与食伤承接的窄复核)。

## 4. 从十神方向到具体五行与可用性

方向确定后，以本候选日主的生克关系映射五行，核对context中已有十神，不借另一个候选的对应关系。区分：本命已有并可讨论的通道、目前缺少但只能条件性讨论的方向，以及尚未证明能发挥作用的藏干。

不能因为需要印就说所有印、所有同五行事物都有利；缺某元素不是取用依据。普通扶抑选出的方向也不自动覆盖调候、月令格局或特定运年的结论。原局与岁运分开，不能直接从本命方向推出具体升职、收益、职业、颜色或地理选择。

## 5. 将论证落到现有报告字段

无需新增JSON格式：

- strength：conclusion给暂定倾向与普通格假设；supportRefs/counterRefs和counterReview解释依据及反证；conditions写会改变方向的条件。
- balance：conclusion明确主要负荷、采用上表哪条取法、候选十神/五行及理由；不能用“不确定强弱”同时掩盖已经肯定的喜用结论。
- selection：把扶抑候选与格局、调候分开；可以只给有依据的扶抑候选，并说明不能上升为统一或唯一用神。
- conditional表示已有可讨论的条件结论，不是“保证成立”；unresolved须说明是哪种缺口：输入事实不足、关键作用规则尚未核验，或两种有依据的传统取法未能裁决。代码没有输出标签本身不是论证。

一个合格回答应让读者知道：本轮倾向什么、为什么、主要反证是什么、满足什么条件才会改判，以及结论只在哪个语境有效。用户质疑不构成新证据；新增事实或发现推理错误则直接更新并说明。

## 需要具体比较示范时

已列支持与反证却不能说明谁在何种条件下占优时，读取[三类命例分析链](strength-case-chains.md)。区分原作者的作用判断与可计算观察；不能把未决称为两停，或将不同章节的用神合并。
