# 接手续交

```sh
python3 <skill>/scripts/twc.py --project <repo> handoff --draft --online \
  --done "完成接口和错误分支" --next "负责人核对组合测试和审批"
git add -- .team-workflow/tasks/pr-8
git commit -m "twc: hand off pr-8" -- .team-workflow/tasks/pr-8
```

`handoff` 在任务目录写入 `handoff.json` 和 `handoff.md`。内容包括：任务和契约版本、分支、base/head、代码内容哈希、完成/剩余/下一步、每条 AC 和每项检查的状态及执行者、阻碍和未知项。检查状态中 `stale` 表示有过记录但对应的是旧代码、旧契约或旧策略，需要在宣称相应验收通过前重验，不要求在开工前重跑；`missing` 表示从未记录；`not_run` 表示最新尝试未能启动，不可沿用旧通过。目录里只保留最新一份交接，历史由 Git 保存。

- remaining：手写的未完成项，加上所有未 verified 的 AC（自动推导，不靠自报）。
- 输入里的 TODO、TBD、待补充、`...` 等占位文本会被拒绝。
- 平台任务的 `--online` 重新读取 PR，核对平台上的 head/base。本地任务无需平台；已配置平台时显式 `--online` 仍会读取当前账号。
- `--publish` 明确不支持，不发任何请求。

## 排障中的接续

连续修复没有获得新证据时，停止沿用同一假设，先复核复现条件，再在授权范围内补取区分假设的最小日志、数据或运行观察。尝试次数只是重新评估的提醒；不机械地等到第三次才取证，也不因换会话丢弃已有事实。

沿用已有交接字段，不新建尝试数据库：

- `done`：已观察到的现象、复现条件、已执行的方法及结果。明确写出失败或无效的尝试；尝试完成不等于缺陷修复。附可共享的去敏证据引用，区分观察与推断。
- `remaining`：尚未满足的验收、未排除的解释、受影响范围和待裁决事项。只有相应证据支持时才称某个假设已排除。
- `next_steps`（CLI 为 `--next`）：下一项取证或检查，以及什么结果能区分剩余假设；继续沿用原有授权边界。

例如，下列条目展示排障任务中的写法，不代表实际执行记录：

```text
done: 在已批准的测试数据上复现重复导出；仅在连续点击时出现。增加按钮禁用后仍复现，尚不能排除请求或服务端处理重复。
remaining: 重复发生在请求发送还是服务端处理阶段尚未确定；防重复验收仍未满足。
next_steps: 在测试环境记录去敏请求标识与处理次数，区分多次请求和单次请求重复处理，再决定修复位置。
```

共享交接不附原始日志、凭据或本地绝对路径；沿用 [验证与证据](verification.md) 的去敏与引用规则。发现同类位置时，先核对是否同一根因：当前授权内可一并修复并验证，涉及范围外模块或产品行为时先列出影响、确认扩展范围。

新会话先按 `resume` 核对当前代码与证据，再读取这些尝试结果；旧交接不替代现场，也不要求重新走一遍已被证伪的路径。

## 状态含义

| readiness | 条件 |
| --- | --- |
| `not_ready` | 缺契约、契约或接口漂移、验证失败、证据全部过期、AC 未验证、有未提交代码、基线未集成，或仍有未完成工作 |
| `unknown` | 缺必要证据或有人工 AC；本地任务需 integrator 评审；平台任务未刷新或无可核对的交付 PR |
| `advisory_ready` | 本地任务材料齐全可供接续；平台任务还须 PR base/head 一致。按 `readiness_scope` 区分，不代表审批、CI 完整或合并许可 |

同一工作区的后续会话直接 `resume`，不要求为了接续先推送。跨 clone 的材料传递见下文。

## 交给下一个人

提交任务目录并推送任务分支，就完成了交接材料的传递；需要平台可见时，由获授权的人把 `handoff.md` 发到 PR。本地绝对路径、未推送的提交和 `.team-workflow/local/` 都不能当作对方可用的交付。

接手者 fetch 后切到该分支，先 `resume`：它读取已提交的任务目录，报告哪些证据对当前代码仍然有效、上次交接的下一步、交接之后又有哪些提交。核对自己的身份；需要建立/修正绑定或更新已审阅契约时才 `prepare`，验证时机和范围按 [任务循环](task-loop.md) 与项目要求决定。旧证据保留原执行者；不同 Agent 的加载证明分别记录。
