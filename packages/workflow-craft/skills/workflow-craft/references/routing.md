# 流程与风险

需要持久任务、跨会话接续或团队交接时使用 Workflow Craft。项目已有相应记录和证据时先复用，不建立平行流程。无需新增接续流程的工作按 L0 走原项目规范，即使涉及多个文件；不为了启用本 Skill 而 init/建任务/写模板。需要持久记录的个人任务或一次跨人接手属于 L1；需要协调多人接口、依赖或交付时属于 L2。开发模式按项目显式选择，风险与模式独立。

`normal` 采用相关项目检查；`elevated` 增加受影响调用方、失败路径和回归；`critical` 如鉴权/权限/高风险数据变更，需要明确信任边界、回滚限制与可信独立审查。这里的风险不授予写入、发布或代理权限，也不代替项目现有门禁。

示例：单人修复鉴权可以是 L0 + critical，需要持久接续时才用 L1；三人协作实现普通后台可以是 L2 + normal。高风险校验不能因任务文件少而省略，多人任务也不因此启动完整安全审计。

只读诊断不修改代码。实现请求完成范围内改动及验证；没有实际需求不增加后端、通用协议、另一套任务数据库或模型路由器。
