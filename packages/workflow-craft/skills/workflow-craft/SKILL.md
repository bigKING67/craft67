# Workflow Craft

帮助个人或团队跨会话、成员和宿主接续软件任务。遵循宿主指令、用户当前授权及项目 `AGENTS.md`、`CLAUDE.md` 和规格；本工具只补任务、证据与交接，不另建编码规则或审批要求。普通问答、可当次完成的 L0 修改不为本工具初始化流程。

## 选定执行副本

- 已从项目固定 Skill 加载时，使用该副本；不再执行全局选择。
- 从全局入口加载，且需要正式启用或接续持久任务时，先用当前副本的 CLI 执行只读 `entry --host codex|claude|pi`，选择当前宿主。返回项目 `skill` / `cli` 时，后续只使用该固定副本；入口选择已经完成，不再从全局执行任务步骤。
- 返回 `pin_project_runtime` 时，先读本副本的[完整规则](references/workflow.md)了解首次接入；模式已选定且授权覆盖后才执行 `entry --host ... --apply`，随后使用返回的项目 CLI 初始化。缺少模式或名字时按完整规则提醒，不替用户选择，不索要邮箱，不重复询问已有选择或授权。
- 返回冲突、漂移或缺失固定版本时，保留障碍，不回退到全局流程，不自动升级、覆盖或执行未核验的项目副本。全局升级不改变已有项目的版本锁、模式、规则或历史。

## 只读一份完整规则

选定副本后，读取其中的详细规则，再按当前任务加载所需引用：

- **固定副本有 `references/workflow.md`**：直接读取这个文件，无需再读该副本 `SKILL.md` 的同一入口说明；从项目直接加载本入口时也读取本副本的[完整规则](references/workflow.md)。
- **旧固定副本没有该文件**：只读取 `entry` 返回的项目 `SKILL.md`，按旧版自身的说明接续；不要读取全局新版的完整规则来代替，也不要求升级旧项目。
- **尚无项目固定副本**：仅在首次接入需要时读取本副本的完整规则。固定完成后用项目 CLI；已读规则与所选副本内容一致时复用，内容不同时再读所选版本。

已有项目固定副本时，不读取全局 `references/workflow.md`。本会话已经读过且内容未变的完整规则可复用，不重复加载。详细规则中的授权、模式、身份、生命周期、检查和完成边界继续适用；全局入口不作为第二个流程所有者。
