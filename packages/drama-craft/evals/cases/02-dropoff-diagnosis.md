# 输入

现状：一条 P1 冲突质疑 20s 剧情已投放两轮，每轮 3 条同结构素材。
数据：0–10% 段留存正常；70–100% 段（16–20s）明显陡降；点击率与上一版持平。
脚本要点：后厨被同事质问上班化妆 → 递气垫让对方试 → 同事摸脸 → 店长认可 → 结尾展示包装并打价格字幕。
可用素材：AI 生成人物与场景；转化镜有实拍通用素材。

# 要的交付

先定位掉点段与最可能原因（只保留一个假设），再给**一个**变量的改法与改写后分镜表，最后写冻结不变量与下一轮观察指标。不要整篇重写。
