# Changelog

## 0.2.0

内部一致性、可拍性交接与证据口径修订；无新增原型。

**行为变更**

- 三条铁律标注适用范围：仅约束主原型 P1–P5 与 P11；P6–P8 与组件 P9、P10 改用等价硬约束表，不再要求无冲突原型强行设置施压者。
- 原型库拆为两层：主原型（P1–P8、P11）与组件（P9 钩子、P10 转化镜）；P8 可兼作机制收口而不占主原型名额；采集字段改为“一个主原型 + 可选组件”。
- 掉点诊断从固定秒数（3s / 3–8 / 8–15 / 15–25s）改为播放进度百分比分段（0–10% / 10–30% / 30–70% / 70–100%），可同时用于 15s 促销片与 120s+ 剧情线。
- 新增基线口径（≥9 条中位数、指标取自同一报表同一列）与最小判读条件（曝光门槛、48 小时观察窗、同计划同出价同人群），停止条件改为引用该口径。
- 出稿验收拆为“通用项 / P1–P5 与 P11 追加 / P6–P8 追加”，修复验收清单与 P6–P8、P11 原型自相矛盾的问题。
- 复盘卡新增“归因”字段（假设被否定 / 执行失败 / 样本不足）。
- 新增生成交接层：画幅与安全区、单镜生成档位、口型规则、参考图集编号、镜数预算、每镜禁止项；分镜表新增“素材来源”与“参考资产”两列，跨镜一致性检查因此可执行。
- 新增端到端范例 `references/worked-example.md`（P1 20s，含 beat sheet、分镜表、生成交接、变量矩阵、复盘卡、验收）。
- 证据口径：原型库降为“已归类（C 级）”，新增 A/B/C 证据等级、台账字段与 90 天复核周期；README 与 CHANGELOG 不再称“已验证”。
- 机制话术示例标注为结构占位，不得直接作为宣称；新增“宣称有依据”硬约束与合规上游（commerce claim/currentness）。
- 新增冗余声明：本库抽样来自抖音竖屏，其他平台需重测钩子与时长。
- 新增 `adapters/README.md`：单一 canonical 安装（`~/.agents/skills`）、各宿主发现方式与验证状态，明确本包未打 tag、未发 Release，文档级适配不得声称运行时已验证。
- `description` 补充短剧、脚本、爽点、反转、AI 视频等触发词，并写明合规上游。

**校验**

- `check.py` 新增：铁律必须落在“三条铁律”节内且声明适用范围；逐个原型校验必填字段（主原型额外要求情绪路径与爽点）；分类术语（主原型 / 组件 / 观察池）在位；生成交接、素材来源、占位数字声明在位；包文档对比（原型数量与区间 P1–P11、源码版本、CHANGELOG 版本节、README 不得自称已验证）。
- `check.py` 新增 `check_docs`，`main()` 同时输出 Skill 与包文档两类错误；修正原文档中“可在已安装副本内运行”的不实说明。
- 测试从 10 项扩到 17 项，覆盖上述新增检查。

**限制**

- 仍无真实投放数据：所有原型维持 C 级，90 天内需按当期数据复核或降级回观察池。
- 尚未在宿主中做模型行为评估；静态检查通过不等同于新会话生成质量已验证。

## 0.1.0

首个源码版本，尚未发布 Release。

**新增能力**

- 11 个已归类剧情原型（P1–P11），每项含固定思路、情绪路径、爽点、适配条件、已知变体与生产提示；另有 9 条未定型形态的观察池与四段式拼接规则。
- 三条铁律与默认 beat 架构（钩子 → 施压 → 被动不辩解 → 动作自证 → 旁观者反转 → 机制），含分原型时长预算。
- 生产约束：五类场景与选用优先级、六类人像的年龄分层、四类服化道、三种上妆手法、两种剪辑形态、跨镜一致性检查。
- 迭代方法：掉点诊断表、四层变量矩阵、单变量与冻结不变量纪律、迭代记录字段、停止条件、出稿验收清单。
- 交付模板：beat sheet、分镜表、变量矩阵、复盘卡、机制话术三种结构。

**校验**

- `scripts/check.py`：frontmatter、链接可达与不越界、reference 无孤儿、原型编号 P1–P11 连续、铁律与关键约束在位、无占位符与绝对路径。
- `tests/test_package.py`：10 项回归，覆盖缺失 reference、孤儿 reference、断链、越界链接、占位符、name 不匹配、缺 description、铁律被改、原型编号断档。

**来源与限制**

- 内容来源为内容团队两份内部文档《爆款AI剧情采集分类》《AI剧情方向分析》的整理与结构化，属于 2026 年抖音美妆/个护/食品/家清类爆款抽样。
- 未经真实投放 A/B 复核；文档中的商品名、价格、点赞与日期仅用于说明结构，不代表当前在售状态、效果或转化结论。
- 尚未在宿主中做模型行为评估，静态检查通过不等同于新会话生成质量已验证。
