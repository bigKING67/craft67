# Drama Craft

给电商短视频写剧情，不是写文学。目标是让陌生人在 3 秒内留下、在 20–40 秒内看完一次态度反转、在最后 2–4 秒记住一个具体数字。默认交付可直接生产的脚本、分镜和下一轮迭代变量，不是散文式创意说明。

产品事实、价格机制、卖点和合规口径以用户提供的为主；不替用户编造功效、销量、资质或医疗表述。品类功效与价格宣称的判定不在本包，按 commerce 系列的 claim/currentness 结论执行；用户没给就按最小假设开工并标注"待确认"，不因信息不全停摆。

本库的节奏与原型来自抖音竖屏抽样，小红书、视频号、私域等平台需重测钩子长度与整体时长，不要直接照搬。

## 先判断要哪一种交付

| 用户给了什么 | 交付什么 | 不要做什么 |
| --- | --- | --- |
| 产品 + 卖点 + 机制 | 2–3 个不同**机制**的剧情方向，各带 beat 与分镜 | 只换场景或演员的伪"多方向" |
| 已有脚本要改 | 掉点诊断 + 单变量改法 + 改写后分镜 | 整篇重写却说不清改了什么 |
| 有成片要复盘 | 原型归类、情绪路径、爽点、可复用模板 | 用点赞数代替转化判断 |
| 要批量产能 | 原型库 + 变量矩阵 + 迭代记录 | 一次改五个变量当"测试" |
| 只要一句钩子或一句话术 | 直接给 5–10 条候选，标注赌的是哪条心理 | 附上完整流程文档 |

## 三条铁律

来自真实爆款抽样，先遵守再谈创新。**适用范围：主原型 P1–P5 与 P11**。P6–P8 与组件 P9、P10 用下方等价硬约束替代——不要为了让剧本"符合铁律"给无冲突原型硬塞施压者。

1. **施压者永远不是主角**：顾客、婆婆、孩子、未婚夫、老公、皇帝、老板、路人。主角处在被否定、被抢、被抛弃、被误会的位置。
2. **主角几乎不反驳**：反击靠一个动作（试用、上妆、擦唇、开箱）或第三方一句真话（"本来就是她全款拿下的"）。让主角长篇辩解会直接杀死爽点。
3. **机制压最后 2–4 秒，且必须带具体数字**：39.9 买一送一、40 分钟发好面、双十一拍一发三、工资 2000 都用得起。没有数字的机制等于没有机制。

等价硬约束（无施压者、或全片即机制的原型）：

| 原型 | 替代硬约束 |
| --- | --- |
| P6 拟人 | 两条产品必须有明确人群分工，说服力靠对比信息密度；IP 与形象授权先确认 |
| P7 视觉冲击 | 一个意象只解释一个卖点，第 10 秒前完成绑定；不得用意象暗示医疗或治疗作用 |
| P8 促销氛围 | 数字、单位、时效齐全，价格锚点有依据；没有锚点不得使用该原型 |
| P11 栏目 | 前 3 秒点名具体困扰；专家/明星素材授权范围先确认；结论必须落回卖点 |
| P9 / P10 组件 | 不承担施压与反转：P9 只负责 1–3s 留人，P10 只负责 2–4s 效果可读 |

## 默认 beat 架构

P1–P5 与 P11 的骨架几乎同一条链，长度按原型调，顺序不要打乱：

```
钩子 1–3s → 施压/落差 → 被动不辩解 → 一个动作自证 → 旁观者态度反转 → 机制 2–4s
```

P6–P8 按各自固定思路走（见原型库）；P9 作为前置钩子、P10 作为转化镜嵌入任意主原型。

时长预算：

| 原型类型 | 整条时长 | 单镜节奏 |
| --- | --- | --- |
| 冲突质疑、情绪落差、疑问钩子 | 20–40s | 2–4s 一镜 |
| 人物反差 | 约 20s | 2–3s 一镜 |
| 古装宫斗 | 40–60s（完整剧情线 120s+） | 3–6s 一镜 |
| 视觉冲击 / 功效可视化 | 15–30s | 1.5–3s 一镜 |
| 促销氛围 | 约 15s | 1–2s 一镜 |
| 猎奇钩子 | 1–3s 独立前置 | 单镜 |
| 一镜到底上妆 / 补妆 | 2–4s 独立转化镜 | 单镜 |

掉点判读按播放进度百分比分段（0–10% / 10–30% / 30–70% / 70–100%），不按固定秒数；换算与基线口径见 [references/iteration-loop.md](references/iteration-loop.md)。

## 工作流

1. **定输入**：产品、客单价与机制、目标人群、可用场景、不能碰的说法、功效与价格的合规依据。缺项标"待确认"，不自行发明。
2. **选原型**：从 [story-patterns.md](references/story-patterns.md) 的主原型里挑 2–3 个，彼此必须在**冲突来源**或**说服机制**上不同，不能只是换场景；需要时再叠加 P9 钩子或 P10 转化镜。
3. **出 beat sheet**：每个 beat 写清谁施压、主角做什么动作、谁反转、第几秒发生。具体格式见 [output-templates.md](references/output-templates.md)。
4. **出分镜表**：镜号、时间码、景别、画面动作、台词/字幕、音效、承载卖点、素材来源、参考资产、生成要点、风险。
5. **过生成交接**：画幅与安全区、单镜生成档位、口型需求、参考图集编号、镜数预算，按 [production-craft.md](references/production-craft.md) 的交接表逐项填完。
6. **过生产约束**：核场景、人像、服化道、上妆与剪辑方式；AI 拍不出来的动作不要写进关键卖点。
7. **给迭代方案**：按 [iteration-loop.md](references/iteration-loop.md) 输出本轮改哪个变量、保留哪些不变量、下一轮看什么指标。

交付顺序固定：**先脚本和分镜，再机制解释，最后风险与未覆盖项**。不要把方法论放在作品前面。完整范例见 [references/worked-example.md](references/worked-example.md)。

## 生产硬约束

- **AI 上妆特写不作为卖点证据**：AI 上妆生硬、效果差，转化镜头压到 2s 左右，或直接硬切到实拍通用素材。
- **一镜到底单独成镜**：2–4s，从素颜到完成逐渐放大，不要塞进对话戏中间。
- **产品外观与文字优先一致**：包装、色号、瓶型跨镜不得漂移；避免让 AI 生成中文文字（价格、参数用字幕层解决）。
- **场景服务痛点**：暗沉、脱妆、气色差、出油要在画面里被看见，不靠台词宣称。
- **人物年龄分层不混淆**：年轻无明显皱纹，中年只有轻微自然细纹，老年皱纹与松弛清晰，小孩无妆。过度磨皮会让反转失去可信度。
- **正向人物做衬托**：低饱和素雅配色，视觉重心落在面部效果；反向人物要么老旧朴素要么浮夸艳俗，一眼可辨。
- **竖屏与安全区**：默认 9:16，主体与字幕避开上下边缘，平台 UI 会覆盖底部。
- **每镜标素材来源**：AI 生成、实拍、图库三选一；转化镜与质地特写默认实拍。
- **宣称有依据**：功效、时长、价格锚点必须来自用户提供或 commerce 侧 claim 结论；原型库里出现的示例数字只能当结构占位，不得直接写进成片当宣称。

## 常见失败模式

- **有冲突没反转**：施压成立但主角没有可看见的自证动作，观众情绪停在憋屈。
- **有反转没机制**：结尾停在"她真好看"，没有价格、没有数字、没有下一步动作。
- **主角太会说**：台词超过两句就变成辩论赛，爽点被稀释。
- **卖点与场景无关**：持妆卖点写在居家梳妆台，脱妆痛点永远拍不到。
- **给无冲突原型硬套铁律**：给 P7、P8 加施压者，把 15s 的机制片写成 40s 的四不像。
- **把 AI 当实拍**：写了需要真实质感的上妆特写、产品质地细描，成片必然崩。
- **把执行缺陷读成创意结论**：转化镜崩、字幕错、人物不一致属于生成层，先修执行再改方向。
- **伪多方向**：三个方向共享同一冲突来源，测出来的是运气不是创意。
