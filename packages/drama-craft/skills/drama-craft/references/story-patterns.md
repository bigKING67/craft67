# 剧情原型库

来源：2026 年抖音美妆 / 个护 / 食品 / 家清类 AI 剧情带货爆款抽样分类。每个原型都给固定思路、情绪路径、爽点、适配条件与已知变体；标签沿用采集表原始分类，便于和运营分类对齐。

选原型的顺序：先看**冲突来源能不能在现有场景里成立**，再看**说服机制是否与卖点匹配**，最后才看时长和画面成本。同类原型连续用三条以上会互相稀释，同一账号要轮换冲突来源。

## 两层结构：主原型与组件

- **主原型**（P1–P8、P11）：能独立承担一条视频的冲突来源与说服机制；一个项目只选一个。
- **组件**（P9 钩子、P10 转化镜）：只承担留人与效果可读，不承担冲突与反转，可与任意主原型拼接。
- **P8 双身份**：既能作为独立主原型，也能作为其他原型的"机制收口"尾段；作为收口使用时不计入主原型名额，但机制数字与锚点要求不变。

打标签的写法是 `主原型 P1 + 组件 P9/P10`，不是"P1 加 P9 两个主原型"。

## 证据等级与复核

原型库是**归类结果**，不是投放验证结果。等级口径：

| 等级 | 含义 |
| --- | --- |
| A | 有本方投放数据支持：≥3 轮单变量、样本与数据可追溯 |
| B | 有多条同结构样本，但无本方投放数据 |
| C | 来自抽样归类的结构假设，单条样本量未逐条留档 |

- 本库 11 个原型**均为 C 级**：来源是对 2026 年抖音美妆/个护/食品/家清爆款的抽样归类，单条样本数、采集起止日与链接未逐条留档。因此称"已归类"，不称"已验证"，也不构成效果承诺。
- 自建库必须留台账，字段：原型、样本数、采集窗口、来源链接、复核日期。台账不足 5 条的结构只能进观察池。
- 默认复核周期 90 天；到期未复核的原型降级回观察池，或按当期数据重新定级。

## P1 冲突质疑型 · 20–40s

- **固定思路**：发起质疑 / 对立冲突 → 主角陷入被动委屈 → 提供体验 / 效果自证 → 对立者态度反转、主动认可 → 机制说明。
- **情绪路径**：被质疑 → 解释 → 给质疑者试用 → 被认可。
- **爽点**：打破质疑、收获认可。
- **适配**：所有品类，门槛最低、出现频率最高。素颜霜、粉底、睫毛膏、食品、包装类都能用。
- **已知变体**：店员被质问"谁让你用粉底液化妆的"；后厨质问睫毛；公交掀翻泡面后被反种草；保姆质疑雇主乱花钱；职场幻想里老板客户抢货。
- **生产提示**：质疑者必须外化（顾客、同事、婆婆、老板），主角台词控制在两句内；自证动作要单镜可读。

## P2 情绪落差型 · 约 20s

- **固定思路**：建立落差（人物矛盾 / 颜值落差）→ 引入产品试用 → 可视化效果对比 → 他人认可 / 态度转变 → 引导种草（问渠道 / 进直播间）。
- **情绪路径**：委屈或尴尬 → 好奇 → 惊艳 → 认可 → 主动索取。
- **爽点**：从被嫌弃 / 被同情到被关注，靠产品夺回主动权。
- **适配**：需要明确前后对比的品（素颜霜、粉底、面膜、唇部护理）。
- **已知变体**：小孩着急替母亲找路人借产品；丈夫嫌没化妆不带出门；婆婆皮肤状态比儿媳好；被退婚时要求退还产品；丈夫嫌弃后妻子逆袭。
- **生产提示**：落差必须在首帧可见（素颜 / 暗沉 / 妆花），不要靠台词描述；对比用同机位、同光线、半脸或硬切。

## P3 疑问钩子型 · 20–40s

- **固定思路**：钩子（悬念 / 反常对话）→ 情绪铺垫（伤心 / 疑惑 / 尴尬）→ 产品出场 → 效果展示 + 对方认可 → 落点种草。
- **情绪路径**：疑问 → 被反驳 → 好奇 → 认可。
- **爽点**：疑问被解开，且答案指向产品。
- **适配**：有认知门槛或需要解释成分、用法的品（成分型护肤、多效底妆、工具类）。
- **已知变体**：中年夫妻只问不答；仿拍电视剧片段（找小三 / 店员询问）；高铁偶遇没被认出；乘客边用边提问。
- **生产提示**：问题必须是观众自己的问题，不是品牌想解释的问题；答案在第 8–12 秒出现，太晚完播就掉。

## P4 人物反差型 · 约 20s

- **固定思路**：用戏剧钩子留住人 → 制造情绪起伏（先压 / 先意外）→ 靠产品或福利完成反转闭环 → 情绪高点完成种草。
- **情绪路径**：错愕 → 愤怒或不服 → 心动 → 顺势接受。
- **爽点**：身份、性别、阶层或能力反差带来的秩序翻转。
- **适配**：机制型福利好用的品；也适合低关注度品类靠反差破圈。
- **已知变体**：肌肉男到柜台买假睫毛，最后承认是女生并享一折；保姆质问主人买贵月饼；一觉醒来只有自己会做珍珠棉，老板抢货。
- **生产提示**：反差要在首帧成立（造型、台词、身份字幕任选其一），不要靠后期解释；反转后立刻接机制。

## P5 古装宫斗型 · 40–60s

- **固定思路**：发难 / 窘境 / 疑问开篇 → 陷入被动处境 → 引出产品 → 效果 / 价值揭晓 → 高位者认可、态度反转。
- **情绪路径**：被质疑 → 紧张 → 惊艳 → 主动询问。
- **爽点**：低位者用效果打脸高位者，地位反转。
- **适配**：有视觉辨识度的彩妆与洗护；国风调性品牌。
- **已知变体**：贵妃逼妃子卸妆验素颜；妃子脱妆被当成鬼，靠气垫重获宠爱；模仿长今热梗问成分；太子妃被淋雨后靠持妆粉底不脱妆。
- **生产提示**：双角色互动为主，超过两个主要角色会分散；完整剧情线（120s+）需要一条主冲突（抢婚、选秀、失宠）再自然植入。

## P6 拟人类型 · 约 20s

- **固定思路**：
  - 文物 / 名画拟人：出现皮肤问题（日晒发红、干裂、需要修护）→ 顺势拿出产品解决 → 植入修护卖点。
  - 动物 / 拟人角色：直接抛出两款同类产品（新旧气垫、2.0 / 3.0 版本、金盖 / 黑盖）→ 对比差异、划分适用人群 → 择优推荐新款 → 带直播间福利。
- **情绪路径**：新鲜感 → 好奇对比 → 结论明确。
- **爽点**：把"选不出来"变成"有人替你选"。
- **适配**：有版本迭代、有多 SKU 需要分工的品；IP 形象辨识度高的品牌。
- **已知变体**：人面狮身像晒红、兵马俑干裂、蒙娜丽莎修护、小人国修城墙；小猫解释两款大白饼适用场景。
- **生产提示**：IP 形象涉及版权，商用前确认授权；没有真人冲突时，说服力全靠"对比信息密度"，两条产品必须有明确人群分工。

## P7 视觉冲击 / 功效可视化 · 15–30s

- **固定思路**：意象化痛点 / 浪漫场景铺垫 → 视觉化展示成分或原理 → 呈现修护、滋养效果 → 传递产品价值、种草。
- **情绪路径**：不适感 → 理解原理 → 舒适与信任。
- **爽点**：把看不见的功效变成看得见的画面。
- **适配**：成分、质地、修护、补水类；需要解释"为什么有效"的品。
- **已知变体**：面部干裂对应土地干裂；深海提取成分；花蕊里的分子结构；城墙修补对应屏障修护；ASMR 展示质地。
- **生产提示**：这类最容易变成纯视觉炫技，必须在第 10 秒前把意象与具体卖点绑定（一对一，不要一个意象解释三个功效）。

## P8 促销氛围 · 约 15s

- **固定思路**：爆料 / 热闹抢购场景 → 烘托稀缺与优惠氛围 → 抛出价格、福利机制 → 刺激下单。
- **情绪路径**：好奇 → 紧迫 → 怕错过。
- **爽点**：内部消息感与抢到便宜。
- **适配**：大促节点、限时机制、清库存；不需要讲功效时。
- **已知变体**：私下打电话告密；超市哄抢；美妆柜台抢购；发布会主持人口播机制；直升机吊横幅。
- **生产提示**：机制必须具体到数字、单位和时效；没有价格锚点时不要用这个原型，观众会认为只是吆喝。

## P9 猎奇钩子 · 1–3s（前置，可与其他原型组合）

- **固定思路**：反常或夸张的产品视觉动作（钩子）→ 指出错误玩法 → 纠正、示范正确用法 → 展示质地、效果、卖点。
- **情绪路径**：这是干什么 → 我是不是也做错了 → 原来要这样用。
- **爽点**：纠正错误带来的"学到一手"。
- **适配**：质地特殊、用法有讲究的品（粉饼、气垫、散粉、泥膜、隔离）。
- **已知变体**：用刀刮粉饼；对着气垫刮丝；一按精华流出；从冰箱掏出化妆品；冰柜里贴痛点；散粉撒落。
- **生产提示**：钩子只负责 1–3 秒留人，之后必须回到卖点，否则完播虚高、转化空转。

## P10 一镜到底上妆 / 补妆 · 2–4s（独立转化镜）

- **固定思路**：单镜从素颜到完成，逐渐放大面部，呈现控油、磨皮、服帖、光泽等即时效果。
- **适配**：所有底妆。常作为 P1–P5 的转化镜头嵌入。
- **已知变体**：男生对镜定妆逐渐放大；满脸油光一键磨皮；近距离展示上脸光泽。
- **生产提示**：AI 上妆生硬，本镜要么压到 2s 内、要么直接硬切到实拍通用转化素材；不要让它承担"产品好用"的唯一证据。

## P11 AI 新闻 / 栏目型 · 约 9s

- **固定思路**：主持人抛出受众痛点 → 引出明星、博主上手演示并讲解卖点 → 展示上脸使用效果 → 种草传递产品价值。
- **情绪路径**：被点名 → 看到解法 → 信任背书。
- **爽点**：栏目感带来的权威与"被科普到"。
- **适配**：需要第三方背书、有明星或达人素材授权的品；换季、敏感、通勤等痛点型叙事。
- **已知变体**：新闻演播室形式；科普口播；明星同款上身演示。
- **生产提示**：栏目壳子只是包装，痛点必须在前 3 秒点名具体困扰；涉及明星素材必须确认授权范围，不虚构代言关系。

## 组合规则

真实的爆款很少只用一个原型，常见四段式拼接：

```
P9 猎奇钩子(1–3s) → P1/P2/P3/P5 主原型(施压→自证→反转) → P10 转化镜(2–4s) → P8 机制收口(2–4s)
```

拼接时只保留一个主原型。两个强原型叠加会让每条 beat 都变短，观众看不懂关系，反而掉完播。

## 采集字段（沿用内容经理分类表，便于与运营对齐）

| 字段 | 要求 |
| --- | --- |
| 开头截图 + 视频数据 | 点赞、发布日期、平台；点赞只作参照，不作结论 |
| 参考视频链接 | 原始链接，不转述 |
| 视频分析 | 关系、剧情走向、情绪路径、爽点一句说清 |
| 场景 / 服道化 | 具体到房间、门店、交通工具或古风场景；服饰颜色与身份 |
| 卖点介绍 | 用观众话说的卖点，不是品牌说法 |
| 主推产品 / 客单价 | 产品名 + 价格 + 机制数字 |
| 原型标签 | 一个主原型（P1–P8、P11）加可选组件（P9 钩子、P10 转化镜）；打不下主原型的进观察池 |
