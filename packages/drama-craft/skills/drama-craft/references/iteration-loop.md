# 迭代方法与变量矩阵

剧情迭代不是重写文案，是**在受控条件下换掉一个能影响结果的变量，并留下可对照的记录**。没有保留矩阵的"迭代"只是反复喜好。

## 一、先建立原型库，再谈迭代

1. 取同品类、同人群的近 20–30 条爆款，逐条填采集字段（见 [story-patterns.md](story-patterns.md) 末尾表格）。
2. 每条只打一个主原型（P1–P8、P11），组件另记（P9 钩子、P10 转化镜）；打不下主原型的进观察池。
3. 某一原型累计不足 5 条时，不得当作"验证过的套路"复用，只能进观察池。
4. 从每类里抽出**固定思路**（谁施压、主角做什么、谁反转、第几秒出机制），写进原型库。抽不出统一结构的，说明该分类本身是拼凑的。

原型库的用途是缩短第一稿时间，不是让你抄同一条。抄结构、不抄台词与场景。

## 二、诊断：先定位掉点，再决定改什么

先看真实数据分段的留存，再看画面，不要凭观感说"开头不够抓人"。

掉点按**播放进度百分比**分段，不按固定秒数：同一张表要同时适用于 15s 促销片和 120s 剧情线。换算示例：20s 的 0–10% 是 0–2s，40s 是 0–4s，90s 是 0–9s。

| 进度段 | 屏幕上的 beat | 典型数据表现 | 最可能的剧情原因 | 优先改的变量 |
| --- | --- | --- | --- | --- |
| 0–10% | 钩子：首帧关系与冲突 | 前 3 秒留存低 | 钩子没有冲突、首帧看不出关系、反差没成立 | 钩子类型（P9 前置）、首帧画面、第一句台词 |
| 10–30% | 施压/落差：谁在欺负谁 | 不到 1/4 就掉 | 施压者身份不成立、观众不懂谁在欺负谁 | 施压者身份、关系字幕、场景 |
| 30–70% | 自证与反转 | 中段掉 | 冲突不够狠、自证动作看不见、反转出现太早 | 冲突强度、自证动作、反转时间点 |
| 70–100% | 机制收口 | 末段掉 | 机制不清楚、没有数字、没有下一步动作 | 机制话术、价格锚点、引导动作 |
| 全程 | 完整 | 完播高但点击低 | 剧情好看但与产品无关，爽点没落到产品上 | 产品出场时机、卖点绑定方式 |
| 全程 | 完整 | 点击高但转化低 | 机制与价格没有竞争力，或卖点不可信 | 机制结构、对比证据形态、人群匹配 |

无施压者的主原型（P6、P7、P8）在 10–30% 段没有"施压"，对应的是"信息不对等 / 不适感 / 稀缺氛围"是否成立；分段与变量顺序不变。

一次只处理一个掉点。同时改钩子和机制，永远不知道是哪边起作用。

### 基线怎么定义

停止条件和每轮结论都依赖基线，口径必须先固定：

- 基线 = 同原型、同人群、同机制的前一轮结果，取**至少 9 条素材的中位数**；不用单条，不用均值。
- 指标名称以投放后台字段为准：不同后台的同名字段口径不同，结论里要写明取自哪个报表的哪一列（例如 3 秒留存取同一报表的同一列）。换报表就要重建基线。
- 基线与本轮之间，除被测量变量外必须全部冻结；基线只在整轮结论成立后更新一次。

## 三、变量矩阵（单变量原则）

按这个顺序逐层测，越靠上影响越大：

| 层级 | 变量 | 取值示例 |
| --- | --- | --- |
| 一 | 原型 | P1 冲突质疑 / P2 情绪落差 / P3 疑问钩子 |
| 一 | 冲突来源 | 顾客质疑 / 婆婆比较 / 丈夫嫌弃 / 孩子护母 / 同事攀比 |
| 二 | 钩子形态 | 反常动作 / 反常台词 / 结果前置 / 身份反差 |
| 二 | 场景 | 居家梳妆台 / 商场专柜 / 高铁 / 厨房 |
| 三 | 自证动作 | 涂抹 / 按压 / 擦拭 / 开箱 / 递出去让对方试 |
| 三 | 转化镜形态 | 硬切对比 / 2s 上妆 / 实拍通用素材 |
| 四 | 机制话术 | 价格 + 单位换算 + 时效 / 拍发组合 / 对比原价 |
| 四 | 时长 | 20s / 30s / 40s |

规则：

- 每轮只改 **1 个**变量；需要改两个时，拆成两轮，或明确标注"本轮混合变量，结果不可归因"。
- 每轮至少保留 3 条同原型同结构的对照，否则单条波动会被误读成规律。
- 变量取值不同但机制相同的，不算新方向（换场景、换演员、换配色都属同一方向）。
- 记录每轮的**不变量**（人物关系、原型、卖点、机制、时长），下一轮继续冻结。

### 单条什么时候可以判读

样本量不够时，好看难看都是噪声。最小判读条件：

- 单条曝光低于本账号近 30 天同位置素材曝光中位数的一半，或尚未过投放学习期，结论只能写"样本不足"。
- 单轮观察窗至少 48 小时，且只在同一计划内比较；跳计划、跳出价、跳人群的结果不可归因到创意。
- 变量外的一切必须一致：人群包、出价、时段、落地页、封面。做不到时在记录里标注"混合变量"，不得当成结论。

## 四、迭代记录（每轮必填）

| 字段 | 内容 |
| --- | --- |
| 轮次 | R1、R2… |
| 本轮变量 | 只写一个 |
| 变更前后取值 | 例如钩子：反常动作 → 结果前置 |
| 冻结不变量 | 原型、冲突来源、场景、卖点、机制、时长 |
| 样本量 | 本轮投放条数 |
| 观察指标 | 3s 留存、完播、点击、转化 |
| 结论 | 保留 / 淘汰 / 需要更多样本 |
| 淘汰理由 | 写清是假设被否定，还是执行没做到（两者结论不同） |
| 归因 | 三选一：假设被否定 / 执行失败（生成崩、字幕错、演员不对）/ 样本不足 |

三条纪律：

1. **假设被否定 ≠ 执行失败**。执行没做到（演员不对、转化镜崩、字幕错）时，不要改创意方向，先修执行。
2. 单条爆了不改结论；至少 3 条同变量同结构朝同一方向变化才算信号。
3. 点赞、评论只能作参考，不作主指标。剧情带货的判据是留存—点击—转化。

## 五、停止条件

出现以下任一情况就停手，回到原型库重选，而不是继续微调：

- 同一原型连续 3 轮、每轮 ≥3 条，3 秒留存仍显著低于按上文口径固定的基线。
- 完播上去了但点击连续两轮不涨（说明爽点与产品脱钩）。
- 需要靠改价格机制才能带动数据（说明剧情没承担说服功能）。
- 同一卖点已经用过 3 种以上原型仍无起色（大概率是产品—人群不匹配，属于商业策略问题，不在剧本层解决）。

## 六、反模式

- **只改措辞当新方向**：文案换了、结构没换，测的是运气。
- **一次改五个变量**：结果好看也不知为什么，难看也不知改哪里。
- **把 AI 上妆特写当卖点证据**：画面必然生硬，数据下滑被误判成剧情问题。
- **用点赞当地域性结论**：点赞受话题和流量池影响，与转化相关性弱。
- **无限迭代**：没有停止条件，团队会把预算烧在已经不成立的假设上。
- **只复制台词的抄片**：结构没抽出来，换产品就崩。
- **把执行缺陷读成创意结论**：转化镜崩、字幕错、人物不一致属于生成层，先修执行再改方向。
- **跨平台照搬**：本库抽样来自抖音竖屏，换平台先重测钩子长度与整体时长。

## 七、出稿前验收（逐条打勾）

**通用项（所有原型）**

- [ ] 主原型明确且只有一个；用到的组件已标明（P9 钩子、P10 转化镜，或 P8 作机制收口）。
- [ ] 场景能看见痛点；前后对比同机位同光线。
- [ ] 转化镜 ≤ 2s 或硬切；未让 AI 承担真实质地细节。
- [ ] 人物年龄、发型、服装跨镜一致；产品包装跨镜一致。
- [ ] 每镜标了素材来源（AI / 实拍 / 图库）与参考资产编号。
- [ ] 画幅、安全区、单镜生成档位、口型需求已按生成交接表填完。
- [ ] 没有 AI 生成的中文文字；价格参数走字幕层。
- [ ] 功效、时长、价格锚点有用户提供或 commerce claim 结论支撑，示例数字未被直接当宣称使用。
- [ ] 无虚构功效、无未授权明星肖像或 IP 联名暗示。
- [ ] 交付含分镜表、变量矩阵与本轮不变量清单。

**主原型 P1–P5、P11 追加**

- [ ] 施压者不是主角；主角台词 ≤ 2 句。
- [ ] 有一个 1–2 秒可读的自证动作。
- [ ] 反转来自旁观者或第三方，不来自主角自夸。
- [ ] 机制在最后 2–4 秒，含具体数字。

**主原型 P6–P8 追加**：按 SKILL.md 的等价硬约束逐条核——P6 两条产品有人群分工且授权清楚，P7 一个意象只解释一个卖点且第 10 秒前绑定，P8 数字加单位加时效且锚点有依据。
