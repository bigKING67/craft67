# 填完的范例：P1 20s 一条完整交付

模板是骨架，这份是填完的样子。用途是让人对着看字段该写到什么程度，不是拿去改台词复用。

**示例声明**：产品、价格、台词、人物全部是结构占位，不对应任何真实品牌或在售机制；本页不包含任何投放数据，任何绝对数值都必须换成你自己后台同列字段。

## 一、输入（含待确认项）

| 项 | 内容 |
| --- | --- |
| 产品 | 控油气垫（示例占位，非真实品牌） |
| 客单价与机制 | 39.9 两只装 + 送粉扑（示例占位，须换成当期机制） |
| 目标人群 | 18–30 岁油皮、早班通勤、需要长时间带妆 |
| 可用场景 | 后厨/门店后场、商场专柜 |
| 不能碰的说法 | 不提"祛痘""消炎""替代医美"；不承诺具体持妆小时数（无实测依据） |
| 合规依据 | 用户未提供 claim 结论 → 全部功效表述降级为画面呈现，不带时长与医疗暗示；待 commerce claim/currentness 结论补入 |

缺项处理：合规依据缺，按最小假设开工并在交付里标"待确认"，不停摆。

## 二、选原型

主原型 **P1 冲突质疑**（冲突来源：同事质疑上班化妆；说服机制：半脸对比 + 第三方真话），组件 **P10 转化镜**（2s，只负责效果可读）。

不选 P2 情绪落差：本品种草点是控油而非颜值落差；不选 P8：本期没有可用的价格锚点依据。

## 五、生成交接

| 项 | 本片取值 |
| --- | --- |
| 画幅 | 9:16；主体眼线落在上 1/3；字幕基线离开底部安全区 |
| 单镜档位 | 全部 ≤4s，按 5s 档出片后裁切；S02、S06 若工具只出 5s，拆成两个 2.5s 镜 |
| 口型镜 | S01、S02、S03、S05、S06 共 5 镜标口型，台词均 ≤12 字 |
| 参考资产 | CH-01 店员、CH-02 同事、CH-03 店长、SC-01 后厨、PD-01 产品正面与开盖 |
| 素材来源 | AI 6 镜、实拍 2 镜（S04、S07） |
| 镜数预算 | 8 镜，20s 上限 10 镜，未超 |
| 每镜禁止项 | 中文文字、镜面反射、多层手部动作、快速转身、人群特写 |

一致性是资产问题：本片两人同框 3 镜，没有固定 CH-01/CH-02 图集就一定换脸。

## 七、复盘卡（跑完之后填）

| 字段 | 填写内容 |
| --- | --- |
| 实际原型 | P1 + P10，与脚本标注一致 |
| 情绪路径 | 被质疑 → 咽下解释 → 一个动作 → 他人试用 → 第三方证实 → 价格 |
| 爽点 | 同事抢过镜子问怎么买同一款气垫 |
| 掉点 | 70–100% 段（18.0–20.0s）留存陡降；绝对值取自投放后台同一报表列，不在本文档编造 |
| 原因假设 | 机制在最后 2s 才出现，字幕信息量超过一屏 |
| 下一轮变量 | 机制话术：拆成两屏字幕（价格，然后拍发组合） |
| 冻结不变量 | 原型、冲突来源、钩子、自证动作、转化镜、时长 |
| 归因 | 待定：样本不足则不判读；若视频本身生成崩则为执行失败 |
| 是否进原型库 | 不进，属于 P1 已有结构的执行层调整 |

## 八、出稿前验收

通用项：

- [x] 主原型只有 P1，组件 P10 已标明。
- [x] 场景能看见痛点（后厨带妆、出油）；前后对比同机位同光线。
- [x] 转化镜 2s 且为硬切实拍，未让 AI 承担质地细节。
- [x] 人物年龄、发型、服装跨镜一致；产品包装跨镜一致。
- [x] 每镜标了素材来源与参考资产编号。
- [x] 画幅、安全区、单镜档位、口型需求已填。
- [x] 无 AI 中文文字；价格走字幕层。
- [x] 功效表述已降级为画面呈现，无时长承诺；合规结论仍为待确认。
- [x] 无虚构功效、无未授权肖像与 IP 暗示。
- [x] 交付含分镜表、变量矩阵与本轮不变量清单。
